# 变更日志

## v1.0

- **阅读与回源**　Skill 和 CLI 用本地 MinerU Basic 整本 OCR，交付可回源 Markdown 和配图。列表与简表保留字面文本，图题和列表保留上下标，公式表保留行列，续段与续表可定位。
- **复核与重建**　用同一 PDF 和原包免 OCR 重建。单格更正保留同格格式与整表疑点，无法无损更正时指出行列。表体确认绑定行列与区域图，图表子块疑点就地显示。混排中的纯插图页可经整页和逐图核实。
- **核验与发布**　`verify` 核对正文实际图链、配图和报告，macOS 排他发布保护已有结果。旧包可用 `render` 重建，内容变化需复核。
- **安装**　双入口默认本地 ONNX/CPU，可用配置文件或环境变量覆盖，环境变量优先。已有环境需更新读取依赖。

已实测扫描件、混合页、扫描表及新会话双入口。
