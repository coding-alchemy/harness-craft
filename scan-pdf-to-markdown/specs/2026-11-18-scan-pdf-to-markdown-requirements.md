## 1. 一次转换，如何使用结果

用户可以按章节阅读转换后的 Markdown，连同配图一起交给大模型构建问答库，或用于“Vibe 知识大赏”。这几种用法共用一份原文材料。标题交代段落属于哪一节，表头说明数值的含义，图题指向对应的图片。遇到疑点，读者或大模型能在正文看见提示，读者还能据此翻到扫描原页核对。问答和衍生创作由下游完成。

首版建议以中文印刷扫描件验收，覆盖纯扫描件及原生文字与扫描区域并存的文件。参考材料《扫描版 PDF 转大模型友好 Markdown：解析与来源映射工程规范》中的批处理、多引擎切换和检索分块属于扩展方向。引擎、文件布局与命令参数由设计确定。

## 2. 首版需求

### R1 原文与阅读顺序

默认处理整份 PDF，原件只读。物理页从 1 开始编号，空白页和识别失败页也有页标记。Markdown 按原语言、原文和阅读顺序呈现可辨认的标题层级、段落、列表、表格及图文。简单表格保留表头、行名与单元格的对应关系。同页原生文字与扫描区域中的正文均须保留，每段只出现一次。

### R2 配图与识别疑点

图片用相对于 Markdown 的路径引用，移动整个结果目录后仍能打开。原文有图题时保留图题与图片的对应关系。文字、阅读顺序、复杂表格或公式存疑时，在正文对应位置给出可见提示。无法可靠还原的表格或公式保留原区域图，边界无法确定时指向原页。排除重复页眉等内容时记录位置和原因。

### R3 从正文查回原页

标题、段落、图片、表格等每个正文块都有唯一标识。用该标识能找到同一源 PDF、从 1 开始的物理页及该块的原始识别记录。引擎给出坐标时保留原值、单位和坐标空间，能可靠换算时给出原页区域。坐标缺失或无法换算时说明原因，保留页级和原始记录定位。

### R4 结果是否可用

简要质量报告分别给出机器检查（页覆盖、逐块来源、坐标、配图完整性）与原页复核的结果，列出处理范围、空白页、失败页和异常块。空白页须有原页依据。识别失败页保留页标记并说明原因。复核覆盖首、中、末页、样本中出现的难辨版面，以及所有未知或失败项。

| 整体结论 | 判定依据 |
| --- | --- |
| 失败 | 源件不符、漏页、块无法回源、已有坐标非法或引用图片缺失、损坏等完整性检查失败，或有内容的整本未识别出可读正文。说明失败原因，保留上次可用结果。 |
| 降级 | 完整性检查通过且正文可用，但仍有未完成的原页复核、局部识别失败或待核对内容。报告列出受影响的页或块。 |
| 通过 | 完整性检查通过，规定的原页复核已完成，已发现的问题均已核实或修正。报告注明实际抽查范围。 |

### R5 从原始结果重生成

保留原始识别记录、源件身份、引擎版本和图片。用户可以在 OCR 不可用时，用这些材料及同一份源 PDF，在新目录重建 Markdown、配图、逐块来源与质量报告。同一输入、渲染规则与复核状态应得到一致的正文、来源映射和图片内容。报告反映实际复核状态。重建时发现源 PDF 身份不符须说明原因并停止。

### R6 命令行与 Agent Skill

用户从命令行指定本地 PDF 和输出目录，或向已安装的 Skill 提出同一请求。Skill 调用同一本地程序，两种入口交付相同的正文、配图、来源记录与质量报告。Agent 返回正文和报告的位置，说明待复核或失败项。

## 3. 直接验收

选一份真实中文扫描件，先在原页记下一处小节原句、一幅图的图题和一个表格值，供后续独立对照。样本缺少混合页、失败页等情形时用补充样页覆盖。样本副本、输出和验证材料存放在仓库外。

| 场景 | 操作与判定 |
| --- | --- |
| A1 阅读与大模型取材（R1、R2） | 移动整个结果目录，打开 Markdown 并核对页序、标题、列表、段落顺序和图题。检查混合页是否漏段或重复。仅将 Markdown 和配图交给大模型，请它引用该小节的原句、读出指定行列的数值并指出已标记的疑点。对照原 PDF 和 Markdown 检查原句的归属、表头与数值的对应、疑点提示的位置。 |
| A2 逐块查证（R3） | 分别从段落、图片和表格的块标识找到原始识别记录及对应物理页。在原页叠加可用坐标，确认框住目标内容，旋转页另核对方向。缺少坐标时仍能定位原页、查到缺失原因。 |
| A3 区分降级与失败（R2、R4） | 核实空白页与识别失败页。对照一处难辨表格或公式，正文提示、区域图或原页线索、报告应指向同一处。完整性检查通过但尚未抽查时应为降级。抽查完成且疑点均已解决的样本应为通过。移走结果副本中的一张配图，检查应判失败并指出具体引用。另让一次转换失败，核对先前可用结果仍完整。 |
| A4 免 OCR 重建（R5） | 禁用识别引擎，从原始记录和同一 PDF 在新目录重建。比对正文、逐块映射和图片摘要，并核对报告所用的复核状态。换一份同名但内容不同的 PDF 重试，应因源件不符而停止。 |
| A5 两种入口交付（R6） | 在仓库外直接运行 CLI，再向已安装的 Skill 提出同一转换请求。两边都打开正文和报告，检查配图可读、质量结论一致，并各选一块查回原页。 |
