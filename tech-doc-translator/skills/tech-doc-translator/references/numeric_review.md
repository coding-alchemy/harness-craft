# 数字与单位复核辅助

五族译文核验入口（`verify_translation`、`verify_paginated_translation`、
`verify_reference_translation`、`verify_api_translation`、
`verify_pdf_source`）支持 `--numeric-review` 与可选 `--numeric-policy`
（UTF-8 项目约定文件，只作复核上下文记录，不执行为规则）。

## 启用后做什么

- 按当前源/译报告数字、百分比、数量级与单位的原值、位置（章节/表格/
  题注/脚注宿主）与源译差异多重集；分页/多文件按确认顺序覆盖全部输入，
  出现序号不被集合去重吞掉。附着单位写法（如 `5ms`）按已支持单位词典
  识别，同值异单位改写（`5ms→5s`）进入差异多重集并给出对应提示；数字
  左邻与标识符粘连（字母/`_`/`%`/`.`，如 `TPUv3s`、`Model5ms`）仍判
  标识符，不产生正文数量项。代码/公式数字由硬检查保护内容单列；不能
  可靠识别的写法明示未检查。
- 默认口径“保留原值、报告差异、不自动判换算”。合法差异由主 Agent 逐项
  回源修译，或按真实项目口径在复核记录中登记差异 ID（说明项目依据）；
  不换算、不改文、不因剩余数量相等放行。

## 包与恢复/合并

- 包证据的 `numeric` 块绑定口径、检查器身份与本次包差异 ID 多重集，
  `disposed` 须逐项覆盖本次差异；`check_policy` 增加数字口径投影。证据
  与当前输入/口径/检查器不符即失效（进入待复核），重新实际复核并登记后
  恢复。零差异不免独立语义复核。

## 最终交付

- 交付记录中覆盖译文的核验必须同样启用 `--numeric-review`；semantic 复核
  的 `items` 按目标、类别及次数逐项列明本次差异 ID，未闭合项阻断发布。
  统计提示不能覆盖公式/代码/标题/图片/脚注/强 token 的硬失败。
- 未启用时核验明示“未检查”，存量项目行为不变；数字口径文件、相关输入
  或数字模块变化使旧处置失效，须重新实际复核。
