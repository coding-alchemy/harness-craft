# 翻译产物收尾清理（交付验收后的自动清理与复验）

本文件是 tech-doc-translator 翻译任务的收尾清理规则；由 SKILL.md 在翻译任务完成原有交付验收后按需读取。详细资源核验、导出、证据与恢复语义继续由 translation_conventions.md、pdf_export.md、pdf_source.md、images_display.md 维护，本文不复制其算法。

## 触发与边界

- **触发**：翻译任务的原有交付验收全部成立后自动执行——Markdown 硬检查、源对账与语义复核完成；要求 PDF 时 `verify_delivery.py` 通过且视觉复核闭合；交付说明已给出。清理是收尾的一部分，不逐次请求删除批准，交付时提供完整清单与证据。
- **不触发**：仅导出已有 Markdown 的任务；未完成、暂停或失败的翻译任务。
- **范围**：当前翻译项目和本次任务拥有的过程产物。不按目录名扫描知识库其他项目；范围外文件不进入候选。
- **输出优先**：凡可能影响正文、排版、图片、公式、代码、链接、重新导出、直接或间接依赖、工作区恢复或证据回查的文件一律保留；不能证明无影响时保留并说明原因。不以缩减体积、目录整齐或删除数量为目标。

## 资产保护合同

| 角色 | 处置 |
| --- | --- |
| 最终译文、成品 PDF、`00_目录.md`、术语表、原始图片、阅读与导出配置及其全部依赖 | 保留内容与有效路径；不通过改写最终译文制造“无引用” |
| 源快照、解析源、PDF 清单、golden、块映射、源/译工作包和必要项目脚本（`scripts/`） | 按实际核验与恢复用途保留，允许原目录残留；没有分包的项目不新增工作包体系 |
| 验收报告、复核证据、交付身份索引、独有裁决及未解决事项依据 | 归入翻译项目 `evidence/`，保全关联、历史内容与真实身份；新任务从产生时就写入证据目录 |
| 交付级图片映射 | 是导出输入，保持固定位置 `export/images_display.json`；不当作历史报告搬移，不复制第二份 |
| 图片与阅读资源 | 保持在资源目录（`images/` 等），不进入 `evidence/` |
| 可读交付说明 | 沿用现有允许位置，补充清理结果和证据链接；独有口径、未解决项与对应依据逐项保全，不因名称含“总结”“交付”“过程”直接删除；确需合并说明时逐项保全内容与可访问引用 |
| 已确认无用的缓存、失败中间版、过期机械副本 | 无输出、恢复、证据用途且无有效引用后直接删除；内容或用途不明者保留并说明 |

## 候选判定

文件名、扩展名和目录名只用于筛选候选，不单独决定删除。逐项核对内容、实际消费者、保留依赖、独有口径和未解决项：

- 消费者全集：Markdown 的图片、普通/引用式/wiki 链接与嵌入，SVG/CSS 递归后续资源，以及导出命令、配置、交付映射、校验记录、项目 `scripts/` 和恢复/合并/核验入口读取的文件。引用按实际消费者的路径基点解析。
- 不支持或不可靠的引用解析不能以“零匹配”放行；字节重复不删除仍被使用的路径；不按修改时间判定最终交付版本。
- 有效消费者引用与仅供历史说明的文字提及分别判断；不机械改写历史记录。
- 用途不明、证据不足或无法排除影响的文件保留，并在清单中说明原因。

“可重建”仅适用于不承担直接阅读或导出输入的过程产物：删除前在库外临时目录，仅凭保留资产、已有工具和原口径实际重建并核对结果；不借用待删/已删文件、归档、可能变化的网络源或重新作出的人工裁决。不能证明可重建者保留；不为增加删除量另建恢复机制。

## 收尾顺序

1. **确认基线**：原交付验收成立后，读取当前交付记录、项目命令和实际范围，固定交付文件身份、依赖、恢复状态与必要环境。失败、暂停或未完成任务不进入收尾。
2. **判定候选**：从保留资产及其消费者确定保护范围，再逐项检查候选内容与用途。
3. **归位证据**：存量证据搬移保留相对结构与历史内容，逐项登记原路径、现路径和角色；同步当前命令与可读说明中的引用；检查内部相对路径与消费者读取；目标冲突不覆盖。搬移触及复核/身份绑定时按既有合同重新复核，不把历史 PASS 改作当前结论，不自动补签。
4. **记录完整清单**：逐项列出全部候选的路径、用途、大小、身份、处置（删除/保留/搬移）、依据及搬移目标；不用分类汇总或 Top N 代替逐项清单。
5. **检查并删除**：确认必需文件及依赖不在删除集合、必要重建验证已完成、归位后的交付与恢复入口可用。执行前重查候选身份与用途未变化，变化或不确定项退出本轮删除。仅对最终明确集合逐文件直接删除，不生成归档；目录仅在确认为空且无保留用途时删除。
6. **验收并说明**：按下节核验清理后的实际交付；必要检查失败时停止后续删除，如实报告已执行、保留、未完成项及实际影响，不声称存在归档回滚。

## 清理后验收

- 全部保留交付物与清理前内容一致（字节摘要比对）。
- 从实际路径阅读：图片、公式、代码、目录和链接可用；资源扫描与可见效果分别留证。
- 重新导出（仅适用于本次交付含 PDF 成品或有既定 PDF 导出合同的项目）：按原输入顺序、视图声明、映射、环境和口径实际重新导出；完成独立核验与全部页面视觉检查，正文、标题、目录/页码、图片尺寸、公式、代码、链接及未解决项不退化。候选输出放库外临时位置，不覆盖原成品，候选身份不替换实际成品身份。无永久 PDF 成品但有既定导出能力的项目仍实际验证该能力；无 PDF 交付的普通 Markdown 项目不进入 PDF 分支，不新增导出或视觉检查要求，本节的阅读与证据检查仍适用。
- 恢复（按项目形态实际试跑，复用现有工具，不以“入口仍可用”代替实际执行）：
  - 无分包 HTML 项目：仅凭保留的同版本源快照、解析口径与已有项目脚本实际恢复源工作输入，并复跑原核验入口；
  - 分包项目：复跑既有恢复入口，可复用/缺失/失效/待复核状态及对应目标与清理前一致；存在可复用包时用原对应关系实际接续合并并运行既有核验；
  - PDF 源项目：按既有恢复协议从只读源 PDF 与保留清单实际重建源草稿、golden 与快照，并实际复跑源核验与译文核验；
  - 真实缺失、失效或既有失败如实保留并报告，不伪造通过，不借用待删/已删文件、归档、变化网络源或重新裁决补齐。
- 证据：从交付说明与核验/恢复入口实际访问 `evidence/` 的索引、批次与搬移登记；历史证据与清理后结论分开记录。

## 交付说明

最终说明分别列出翻译验收、清理、阅读、重新导出、恢复和证据的实际状态，附完整候选/操作清单、未知项与未解决项及其依据、执行环境与缺口。有阻断缺口时不宣称整体完成；已确认无用项尚未处理时不宣称清理完成；无候选时如实记录无须删除。

## 非目标

归档（zip/tar 等恢复备份）、目录清零、体积指标、全知识库扫描、无授权的存量项目清理、仅导出任务的翻译工作区清理、新增清理 CLI/状态库/依赖数据库/恢复或身份体系。
