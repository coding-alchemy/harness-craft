# 共享术语库

本目录保存可由翻译项目显式选择的共享默认术语库。项目 `术语表.md` 始终优先于本目录中的共享库；不得根据 URL、厂商或文件名自动启用任何术语库。

## 权威文件格式

每个术语库使用稳定标识命名为 `<library-id>.md`，并包含元数据及以下唯一权威表：

| 英文原词 | 中文译法/保留形式 | 处理方式 | 语境/备注 | 来源 |
| --- | --- | --- | --- | --- |

- `英文原词`：术语的原文形式。
- `中文译法/保留形式`：正文采用的中文译法或英文保留形式。
- `处理方式`：只能是 `中文`、`首现中英，后文中文`、`首现中英，后文英文` 或 `英文`。
- `语境/备注`：为空时表示默认口径；只有技术语义或所需译法确有差异时才填写语境。
- `来源`：稳定的项目标识与原表位置；多个来源以分号分隔并按稳定顺序排列。

规范化键是“英文原词 + 语境”。英文原词只做 Unicode 规范化、去除 Markdown 行内代码标记、大小写折叠、首尾裁剪和连续空白折叠；不删除标点、不展开缩写，也不拆分斜杠复合词。

## 维护规则

使用 `scripts/consolidate_glossaries.py` 生成候选草稿与报告。它不会直接覆盖权威文件，也不会裁决中文语义或项目例外。只有项目验收通过且人工批准的无冲突候选，才能通过审阅写入权威术语库。

冲突、解析错误与临时核算报告默认写入 Git 工作区外。更新后应保持权威表按规范化英文键、语境和来源稳定排序，避免无意义 diff。
