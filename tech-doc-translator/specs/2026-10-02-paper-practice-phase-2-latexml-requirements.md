## 1. 核心结果与授权边界

至少一份保留的真实 LaTeXML 论文，在实际项目路径完成原始快照到源 Markdown 的独立对账、翻译、主 Agent 独立回源复核及当前交付验收。公式、正文、代码、图表与脚注的内容、顺序和所属关系可回查；真实损伤、身份错配和未解决项不能被下游源译一致或历史 PASS 掩盖。

全部源家族能取得有位置依据的数字与单位差异提示，主 Agent 按项目口径完成处置；提示不代替语义复核，也不放宽硬检查。

本文只拆分和细化需求，不是设计、执行计划或实施记录。用户同意四期划分并授权编写文档，不等同于批准新增能力、兼容差异或授权实现。

## 2. 当前事实与保留边界

下列事实来自上游本轮离线核验及当前源码；未重跑旧批次，不把历史项目的命中率或交付记录推导为通用能力。

| 基线事实与现行接口 | 对本期的约束 |
| --- | --- |
| `parse_reference_html.py` 只读本地快照，现有公式表示主要消费 `span.math` / `div.math`；原始 `<math alttext="s&lt;Q">` 样例成功输出普通文本 `s < Q`，没有保留公式边界及原 TeX | LaTeXML 需要来源适配；仅修改 Prompt 或比较解析后源与译文，不能证明公式已提取完整 |
| `_html_fidelity.py` 现有实体编码路线能让 `s<Q & x>y` 穿过解析；旧预处理仍改写竖线、删 `\penalty`，无 TeX 节点曾被直接删除 | 保留原文性质，撤回强制私有码位、禁止实体编码及照搬旧预处理的实现限定 |
| `_source_reconcile.py` 从原 HTML 独立取事实；真实 DeepSeek 原始快照当前解析因标题差异失败，旧 clean 快照因未映射的 `rowspan` 失败 | 旧辅助脚本不能直接移植；本期必须对原始快照对账，并保留逐表转换门禁 |
| `verify_delivery.py` 已有 `sources`、选区 / 多快照范围、`table_conversions`、当前来源与资源身份、复核绑定、本次复跑和发布前漂移核对 | LaTeXML 进入这条现行交付链；预处理器打印 PASS 不能取得完整交付资格 |
| 现行约定已要求回源复核数字、单位、否定、条件与交叉引用；工作包恢复 / 合并已有当前输入绑定的人工复核资格 | R5 只补差异定位辅助，复用已有记录与消费规则；缺辅助生成器不等于现行人工流程不可执行 |

## 4. 功能需求

### 4.1 R1：LaTeXML 本地源保真（P1）

来源：旧素材 01 R1.1–R1.8、05 R5.1–R5.3 的有效部分。

#### R1.1 来源身份与可回查快照

- 支持已确认论文的 LaTeXML 本地快照，经一条规范转换接入现有数学 / 参考手册链路。原始快照只读，与转换产物区分保存；解析与校验只读本地输入。
- 无论快照如何取得，记录题名、论文 ID、实际版本、最终 URL、取得时间、原始快照摘要（哈希）及资源获取结果。用独立确认的论文身份核对实际内容身份；不只信文件名、请求 ID、元数据或首个 H1。
- 身份错配、资源失败和回退显式暴露；来源、版本或范围不能确认时停止相应处理。版本无法确认不声称同版本；不自动换成最新版、其他来源或另一版本 PDF。
- 获取快照的辅助能力保持可选，不作为本期离线缺口验证或端到端验收的前提。不把旧站点政策、固定获取通道排序或历史下载成功率设为通用默认。

#### R1.2 公式原文与结构保真

- 保留实体解码后的 `alttext` TeX、行内 / 展示类型、文档顺序、公式组结构与式号。定界包装及式号转换逐项可回查，不以公式数相等证明保持。
- `<`、`&`、换行及原 TeX 命令完整穿过转换，不改写竖线，不删除 `\penalty` 等命令，不以代数或渲染等价放宽原文保持；沿用已批准的表格表示层转换口径。
- 无可用 TeX 的公式逐个定位为未解决项，不删除、不用渲染文本猜测替代。内部占位符在最终源 Markdown 与译文中不得残留。

#### R1.3 浮动体、正文及资源归属

- 正文、图、子图、表格、算法 / 代码清单、图题与脚注保持内容、顺序及归属；代码与行内代码保持既有空白和语义合同，脚注保留引用 / 定义关系。
- 导航、页码等仅在能够识别为装饰时排除。渲染错误节点的内容不得一律删除；无法确认内容或归属时保留内容并定位为未解决项。
- 重复浮动体仅在有同一来源内容依据时去重，记录具体对应；不能只按图号或图题前缀判断。同号不同内容保持独立资源身份，子图展开不得丢失所属关系。
- 优先复用可读、身份可核验的 HTML 资源，不默认替换所有 SVG。需用 PDF 替换时先确认同版本与对应区域，保留裁剪、目检、图内文字 / 图例及来源身份依据；无法确认时不替换、不放行缺图。
- 图片按每次出现保持身份与尺寸链路，沿用实际交付路径和 SVG/CSS 依赖核验。复杂表格使用现行逐表转换映射，单元格、跨度、空值及代码 / 公式对应可回查；不能把表格转代码或照录展平串作为通用豁免。

#### R1.4 原始快照独立对账与漂移处理

- 从原始快照独立建立逐节点到实际源 Markdown 的内容、顺序和结构对应；转换中间产物或转换器自己的统计清单不能成为唯一基准。
- 计数仅作摘要。等数换公式、乱序、丢正文、误删浮动体、改所属关系与无法解释的重复均定位并阻断分派；允许的合并、展开及去重逐项解释并核验结果。
- 转换器或源更新后定位新旧源差异与受影响范围，按现行恢复合同重新核验。不能先覆盖旧源包或重算摘要后追认旧 PASS；无关有效包仍可按当前事实复验复用，不按行号自动迁移译文。

#### R1.5 论文口径

- 图 / 表 / 算法题注复用现有中英对应格式，保留官方编号及所属内容；交叉引用保留官方编号，不能靠添加题注制造完整性。
- References 默认保留英文原文，允许项目覆盖。名称、术语及首现处理服从项目口径，不从单个 LLM 项目复制普遍不译清单或共享词库。
- 提取伪影回到权威源定性，保留原值、依据及处置；无法确认时照录并记录，不把不确定当作已修复。确定内容损伤、资源缺失或结构歧义仍按相应门禁处理，不能仅加说明后完整交付。

#### R1.6 接入当前交付与收尾

- 原始 LaTeXML 快照、转换与结构对应、实际源 Markdown、选区 / 范围及来源资源必须进入现行来源链、独立对账和当前交付身份；不能仅把预处理后的 HTML 声明为权威快照。
- 决定来源、转换及复核结果的实际输入和适用口径纳入已有绑定及发布前复查。相关源、资源、译文、转换依据、规则或检查器变化使受影响旧复核失效；旧证据只读保留，不自动补签。
- 最终按任务实际模式调用当前 `verify_delivery.py`，分别说明硬不变量、源全量对账、语义复核及适用的 PDF / 视觉状态。身份错配、未解决项或缺当前证据不能登记完整完成。
- 原交付验收后沿用现行收尾清理。快照、源 / 译工作包、转换依据、独有口径及恢复 / 核验所需资源受保护；证据归入项目 `evidence/`，交付级映射仍为 `export/images_display.json`。不新增归档或改变交付根允许清单。

### 4.2 R5：数字与单位复核辅助（P1）

来源：旧素材 03 R3.8；03 R3.7 中必要的统计解释。

- 全部现有源家族支持按工作包及最终已确认范围比较数字、百分比、数量级和单位相关 token，列出源 / 译多出项及可回源位置；范围、原值与差异依据清楚可查。
- 差异是主 Agent 的复核线索，不直接断言换算错误、数值语义一致或全文完整。同数不同单位、数值调换归属等仍需回源语义复核；无差异不授予语义完成资格。
- 沿用项目数字保留 / 换算口径。合法换算、题注双语重复等逐项说明并回源确认，不在工具内擅定换算白名单或自动改译文。
- 未处置差异不能登记语义复核完成。处置进入绑定当前源、译文及适用口径的既有复核记录；文件、相关资源或口径变化后旧处置按现行失效规则重新核验。
- 输出明确区分统计提示、未检查 / 未解决项与硬检查失败。统计解释不能覆盖公式、代码、标题、图片、脚注或已裁决强 token 的硬失败。

## 5. 直接验收

以下均为待实现能力的验收标准。本轮文档编辑不构成产品通过；最小样例补齐独立反例，真实项目证据证明主结果。

| 编号 / 需求 | 正向与损伤场景 | 用户可观察的成功证据 |
| --- | --- | --- |
| A1 / R1.2 | 行内 `<`、含 `&` 对齐公式、换行、编号公式组、无 TeX 节点；删除或等数替换公式、改类型 / 式号 / 顺序 | 可用 TeX 的内容、类型、组结构与式号逐项回源一致，字符不被吞掉或改写；无 TeX 节点定位为未解决项。反例从原始快照定位并阻断，不能因另一种偶发错误碰巧失败算通过 |

| A5 / R5 | 各现有源家族的代表输入，工作包与最终范围；`104 billion` → `1040 亿`、百分比漏项、单位变化、逐字保留、双语题注重复及数值归属变化 | 差异有源 / 译位置，逐字保留无差异；合法换算 / 重复可经回源确认闭合，单位和归属问题仍由语义复核发现。无统计差异或统计解释不能取得独立语义资格、不能放宽硬检查 |
| A6 / R1.4、R1.6、R5 | 当前有效证据后改变快照、转换依据 / 口径、译文、资源或检查器；沿用旧处置、未处置数字项、证据发布期间漂移 | 受影响旧复核失效，不能补摘要追认；未处置项阻断语义完成，当前交付重新读事实拒绝漂移。无关有效包可复验复用，失败保留既有有效产物与证据索引 |

## 6. 假设、兼容影响与非目标

- LaTeXML 来源链和数字复核辅助是新增提议，当前 Skill 不能据本文声称已支持；审批状态沿用[总需求](./2026-10-02-paper-practice-requirements.md)第 5 节。具体适配算法、内部入口、映射字段及文件拆分留给获批后的设计。
- 本期把原始快照纳入当前来源和复核事实，转换后源或绑定可能与存量结果不同；按真实差异重新核验受影响范围，不给旧证据自动迁移资格，也不因此默认整篇重译。
- 保留现有源家族、参数用途、人工裁决、恢复 / 合并资格、离线资源、尺寸策略、PDF 出版及清理合同。不新增论文流程引擎、通用文档 IR、状态数据库、第二套身份 / 复核记录或通用复杂表格转换器。
- 不扩大网络抓取、批量检索、站点验证绕过、OCR、LaTeX 源包构建或 PDF 公式自动提取 / 重建范围。不要求四期候选辅助来处理 HTML 图资源，也不把固定 glyph 偏移、旧常数及历史成功率写成通用规则。
- 不采用按行自动迁移译文、公式命令清理、标题 / 图题文本豁免、计数守恒自证、无来源 PDF 补图、LLM 项目普遍不译清单或自动数值换算白名单。

## 7. Karpathy 精简与自检
