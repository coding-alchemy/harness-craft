## 1. 目标与边界

五期增量已进入同一来源、核验、包和交付链。本文保留最终职责和失败场景，取代按阶段重复定义的方案；早期缺口、已作废局部补丁和执行轮次不再作为现行指导。

业务顺序保持：只读原生来源及确认范围 → 来源适配 / 原页裁决 → 候选与独立来源对账 → 安全拆包及自足任务 → 实际翻译、硬检查和主 Agent 回源复核 → 当前资格恢复 / 合并 → 当前交付及适用真实 PDF → 清理后消费。数学、角色和来源有未解决项就停止相应资格，不以事后放宽比较求通过。

普通 HTML、LaTeXML 和 PDF 具有不同原生证据。共享扫描、阅读叶子、资源与资格计算，保留生成和独立核验的分工；不建立通用 IR、来源注册器或第二状态平台。源物化可以逐字对账正文，中文译文仍由硬不变量加人工语义复核，不能要求与英文逐字相等。

## 3. LaTeXML 出现身份与独立正文事实

### 3.1 单一来源依据及范围

保留 `reference` 家族及 `version: 1 / format: latexml`：`snapshot`、`paper_identity`、`decisions`、`correspondences`、`unresolved`，按需要带组、逐表转换及资源替换。身份含预期 / 实际题名、ID、版本、URL、取得时间和独立确认依据；消费者重读文件及可见身份，不信文件名或自报摘要。缺取得资料不编造，不能确认身份 / 范围 / 资源就停止。

`correspondences` 只声明原节点、类型、父属、实际字符范围和具体定界转换。输入中的旧对应不代替本次重建；不存在“生成器同时给快照摘要与转换表，所以自证通过”的路径。原快照不换成 clean HTML。

`selection` 保存实际选区，`markdown.sha256/lines` 保存切片事实。旧依据缺这两键时保留单依据整文兼容；多依据任一缺键拒绝。重复 `--source-adaptation` 按声明顺序，以各自范围、选区、资源基点逐片独立对账，再平移成消费视图；源切片必须按记录行数 / 摘要无缝覆盖。交付条目单快照沿用条目级引用，多快照分别在快照中引用；条目级与多快照二义拒绝。

### 3.2 身份随输出传递

在 DOM 变更前冻结原节点及父属。`math[k]`、`img[n]` 等是本次快照的诊断别名，不是跨版本永久 ID；原图枚举排除 pre 内容，不能采用适配后序号。字面数学在完整语义单元、普通空白折叠之前识别：保留跨标签文字连接及代码 / 链接语境，不逐文本节点孤立扫描，也不把未确认跨行折成单行后登记。

生成侧使用私有临时唯一标记携带每次受保护来源出现，复用代码 / 数学哨兵方式。普通文字转义、表格编码、前缀及图片拆段后再展开；展开前后写入字符数给出局部区间，拼接只累加前缀和分隔长度平移到全局。父对应可以包含多个子片段，但不能替代叶子出现范围。标记冲突、重复或漏展开失败，不回退到文本搜索。

同一个 p 拆出图片前后片段仍有原所属及顺序；行内 / 展示类型从来源事实而非当前宿主决定。公式对应按实际源序组织，包装按实际写出 raw 派生，缺旧字段时只沿用已定义旧口径。输出最后不残留标记。

已删除的成功路径不得恢复：`_host_bounds` 同文本首次命中、`_join` 拼接后反查、隐含 `_host_element` 暂存、仅特殊公式携带身份、候选剩余跨度反推来源、宿主范围 / 表行免检。相同 TeX 是内容比较对象，不能选择出现身份。

### 3.3 独立来源与实际阅读

来源侧以新 DOM 直读文字、代码、链接、引用、原数学及父属，不调用 `paragraph_text` / `render_inline` 等生成出口制造预期。实际侧先读取真实 Markdown 块结构，再读行内叶子；共享扫描先保护数学，普通语法只阅读一次。`_ReadText` 等私有事实区分已读文字与保护叶子，不把字面反引号、实体或形似链接的普通字符串重新解释为角色。

最低事实为“角色、所属、有序片段”：普通文字使用既定 HTML 排版空白 / 阅读归一，代码保留角色和精确内容，数学保留类型及 TeX，链接从真实节点取得标签及规范 URI 目标。代码或数学中的实体、美元、星号与脚注记法不参与普通语法。共享成熟叶子规则不等于共享生成器的遍历、标记或已输出列表。

两侧按角色、所属及出现序比较完整流，受保护叶子不跨代码 / 图 / 条目边界拼接；具体裁决解释后，每个保留内容消费一次。图块行化、展示展开、子图 / 组展开与逐表转换可以一对多，但不是按找到同文就跳过其他内容。源与候选共同漏内容仍由原 DOM 拒绝。

完整流一致后聚合独立的节点 → 实际区间配对，逐项核对声明的节点、类型、父属、定界及字符范围。标题、段落、图片、题注、脚注定义、清单、算法、公式组及未解决容器的非数学对应也要核对。相同内容身份互换、父范围冒充叶子、两个出现争用区间和额外输出均失败。

### 3.4 各类正文的现行事实

| 角色 | 生成及独立核验共同遵守的语义，各自独立取值 |
| --- | --- |
| 段落 / 直属文字 | 文档序完整，图片前后文字独立保留；透明包装不吞直属节点 |
| 标题 / 图表算法题注 | 层级或题注角色、官方编号、父属和全部内部片段；普通文字不冒充标题 |
| 列表 / 参考文献 / 清单 | 容器、条目 / 行序及内部片段；纯字面数学、MathML、行内和展示组合均支持，bullet 是结构不是原内容 |
| 算法 | 直属和包裹后的 p / pre / table 保持原角色；节点分派与孩子遍历区分，不能将正文转代码绕过结构检查 |
| 代码 / 链接 | 块与行内代码精确空白及顺序；标签可含代码 / 数学，目标按成熟 URI 阅读；普通字符串不能伪造真实节点角色 |
| 图 / 子图 / 资源 | 每次出现、父图 / 子图 / 题注关系、实际资源及尺寸；同号不同内容独立，相同资源也不合并不同出现 |
| 表格 / 公式组 | 逐格、跨度、空位、叶子角色，或逐成员类型 / 原文 / 式号 / 次序；表 / 组父范围不免除子项 |
| 脚注 | 引用目标、定义标签、直属文字、段落 / 列表 / 表格 / 代码的真实层级和原序；不再文字 / 代码双队列重排 |

复杂正文表与脚注表复用同一 `table_conversions` 门禁。实际格读取先证明仍是表格，再按具体源格 / 目标格与跨度比较；缺映射、错目标、漏格或把表转普通段落 / 代码拒绝。格内代码不做数学实体改写；管道、LF/CRLF 在已确认真实表格数学处按现有可逆表示解码，不授权表外全局替换。多行公式、相邻式和代码 / 链接叶子仍各自保持角色。

### 3.5 数学与资源的原生依据

MathML 取实体解码一次的 `alttext`；按原 display / 容器确定类型，冲突或空 TeX 进 unresolved。原 TeX 全部首尾 / 内部空白、命令、竖线不清理，`conversion` 区分定界与新增包装换行。仅剥已确认外包装，不套普通块式 strip；删原换行不能重新登记为包装。公式组成员与式号独立，不能用数量或排序后比较。

已有 `SourceMathContext` 只让已独立确认的多行行内数学跨行扫描；字面跨行默认仍未确认。源对账通过后，包 / 译文按类型、表达式、顺序及相关结构消费，不要求译文绝对位置等于英文源。

HTML / SVG 可读且身份可核验时优先复用，路径同名不覆盖，SVG/CSS 依赖进入身份。PDF 替换仅在确有需要且同版本 / 页区 / 裁剪 / 视觉可证明时采用，原始引用和缺失事实仍保存，缺摘要不以 `None == None` 放行。装饰排除、同源重复表示和渲染错误处理逐项有据，不能只按图号 / 字节或标签整类删除。References、双语题注和项目术语按需求 R1.6。

## 4. PDF 页面候选及人工裁决

### 4.1 原生视图与坐标

`inspect` 复用当前 PDF 身份、范围、页尺寸、旋转、双快照及 version=1 清单。text / blocks / dict 各原接口视图分别生成一次并缓存原生结果；不强制共用单 TextPage、不滤图片再重编号补偿，也不改变原 flags、连字码位及各提取视图语义。独立核验重新打开 PDF，不复用生成器缓存。

页号 1 起、区域以 pt 表示，区分未旋转文字提取空间与旋转后显示 / 裁图空间；不得用旋转后 `page.rect` 尺寸解释未旋转文本。链接框先经现有 `derotation_matrix` 回文字空间再匹配字形；裁图和目检使用对应变换。对象及原生字形序号只在相同 PDF / 提取环境有效，无法定位不伪造矩形。

### 4.2 四类候选与证据

`candidates` 增量为 `figure_regions`、`table_cells`、`reading_orders`、`character_defects`，各自显式 empty。共同保存 source_sha256 / scope、页区、原值、对象 / 字形定位、basis、实际 parameters、applicability 和 ambiguities。它们是诊断字段，不写人工 accepted / resolved / resolution_basis。

| 候选 | 方法、保留事实与人工边界 |
| --- | --- |
| 图区 | 用图题、相交 / 连续绘图、位图、邻近文字及栏区提出对象组和备选题注；无大框、上下 / 并排、同号出现各自定位。标签 / 图例、邻接正文 / 表格冲突明确，不靠扩框裁决；图内伪表格保留歧义，不删除页面对象 |
| 表格 | 复用 `find_tables` 的线段 / 文本策略，记录实际参数、适用条件及冲突备选；二维格位、空字符串格、无可靠边界格、疑似合并格和多行表头区别。API 不可用报告局部缺口，人工仍可重建，不自动安装或全局宣告不可用 |
| 阅读序 | 栏感知排序显式给块矩形、栏区、提取 / 建议序、跨栏锚点和双快照对应；保留单栏 / 双栏 / 跨栏冲突，不把固定空格数 / 比例当全部论文可靠阈值 |
| 字符 | 原码位、字形区、上下文、提取值和有依据的建议；异常控制符 / 数学字母数字只是线索，无依据不 ASCII 化或套固定偏移，区分原文异常与提取缺陷 |

人工接受 / 改框写既有 `figure_region`，表格写 `table_region` 及逐格原页裁决，顺序写 `reading_order` / blocks，字符写 `conventions.defects`，排除写 rejected。候选不自动物化表格、不自动更新顺序或源值；启发式疑点也不一律新造阻断 kind。真正未处理素材与已确认缺内容继续受 pending 门禁。

裁图仍核对对象普查、资源摘要、物理显示宽度及原页 / PNG；dpi 不是显示宽度。普通 PDF 表格逐词重读只证明区域文字覆盖，移列 / 空位须逐格原页复核；正式确认数学表格另走第 5 节的源格网与实际格核验。字符正文源保持原重读，译文采用裁决值并复核必要译注；代码在 golden 固化前核对取舍、固化后逐字节，改基准须实际重核。

### 4.3 再勘察与当前资格

同源同范围刷新 candidates，保留 blocks、rejected、conventions、人工分类及顺序。pending 继续按稳定页 / 区域及既有无区域退回键对应，不把可变 kind 当身份；新区域追加，未再发现的旧区域保留待处理。

PDF / 范围变化保存旧裁决和绑定，定位新增 / 消失 / 变化区域并待重核。materialize / verify 同时核对 stale、adjudicated_against 和 revalidate；删 stale、机器 basis 或重算摘要不能取得资格。整清单字节变化沿现有完整交付身份保守失效，不另建候选变化免重核投影；包级复用在全源准入后按第 8 节判断。

## 5. PDF 确认数学合同

### 5.1 原页事实及显式启用

`_pdf_math.py` 承担 PDF 有限确认数学合同，不冒充 LaTeXML 依据。清单保持 version=1，显式 `formula_contract: confirmed-tex-v1`。无声明及新事实的旧清单走原人工路径；任一清单 / 源 / 包已声明或保有新事实却缺必需合同、未知值或冲突时拒绝，不降级。

| 事实 | 必需含义 |
| --- | --- |
| `id`、`origin` | 本次出现唯一 ID；原页未旋转区域及 rawdict 原生块 / 行 / span / 字符的有序片段、原码位 / 文字与提取口径，不由式号或表达式生成 ID |
| `owner`、`slot` | 实际块 / 子块角色与局部位置，表为具体格，脚注为定义 / 子块；不能只写整段包围框 |
| `kind`、`tex` | 人工确认 inline / block 及完整表示，所有空白、换行、反斜线精确保留；PDF 不存在原 TeX 时不称为逐字原文 |
| `label`、可选 `group` | 无式号显式空，有则原可见文本与来源片段；每成员独立身份、顺序、组关系，同号不合并 |
| `confirmation`、`conversion` | 当前原页复核依据、来源 / 范围 / 提取口径绑定；原字形到确认表示的具体转换，区分直接可靠和视觉补足 |

全范围 formula_review 记录逐页接受 / 排除 / 补登记，逐次确认覆盖原片段、所属、类型、TeX、式号和转换。它们改变须实际回页；机器候选不穷举，无候选的公式也可按同一合同补登记。图内数学 / 代码 / 货币等保留各自角色及排除依据。结构不可靠时确认说明补足，无法确认仍 pending，不自动恢复 TeX。

### 5.2 表示与所属

行内单美元、展示双美元，限定多行行内用当前确认构造 `SourceMathContext`。表达式只去合同新增外包装，不 trim 内容。式号不进 `tex`：展示式尾部单独 `\tag*{\text{…}}` 按可见文本转义，配对读取及单层解码后核对，不全局剥任意 tag；行内标签作为同一序列邻接文字，不为排版改成展示。

多行 / 对齐、分式、上下标、矩阵采用原页确认的 TeX 关系；不再存第二数学 AST，结构由确认表示编码、程序逐字核对，表示是否正确由原页证明。渲染失败不能展平、删命令或转代码。

同一 block 的有限 content 有序混合来源文字和数学；相邻文字可合并，不跨保护叶子或所属边界。标题 / 题注保持层级 / 编号；算法说明仍为正文、真实代码走 golden；公式组每个成员独立；脚注定义和引用显式关联，子段落 / 列表 / 表 / 代码按原序；表格同一清单内保存源格网、空位、表头 / 跨度和具体目标格映射，每格读真实 content。

表格数学的内容性管道、LF / CRLF 仅在真实数学跨度内用现有可逆编码，实际块 / 格读取后解码，代码及链接仍各按叶子合同。源表结构损坏不能先全局解码再拍平通过。1–3 空格的合法 Markdown 容器缩进与公式内容空白区分；脚注相邻首行围栏等按真实块解析，不能以字符串外观猜宿主。

### 5.3 精确区间与三输入独立核验

物化按当前来源出现携带临时标记，展开时记录实际写入区间，拼接按字符数平移；块映射保存左闭右开的 Unicode 字符 `md_start/end` 及数学出现，md_lines 仅诊断，偏移属于本次源摘要。表格 / 脚注变换同步产生实际区间，不能最后全文替换再追认旧坐标。先独立核验候选，后同组发布，不改人工清单或交付索引。

独立核验有三份输入，各自作用不可替代：

1. **原 PDF：** 另开文件，核对身份 / 范围 / 环境和原生字形片段；同框同词不替代具体位置，不接收生成缓存。
2. **当前人工确认：** 内容、类型、结构、式号、所属及具体转换，补足提取无法证明的关系；不能从候选反算预期。
3. **实际 Markdown：** 先按数学、表、脚注的实际块规则取结构，共享扫描保护公式再做一次行内阅读；核对定界、标签和真实格位，未确认表格前不解码。

原页及人工事实形成来源流，实际产物独立形成角色 / 有序内容流，对齐后才检验映射的 ID、范围及父属。所有数学恰好消费一次，空确认列表也检额外数学；共同漏式、同文换 ID / 区间、重复、宽范围或正文夹入均失败。生产者同时改摘要 / 区间不能绕过，改变确认须实际重核。程序不鉴别整套伪造人工确认，不新增签名台账或自动数学视觉平台。

### 5.4 全部实际消费者

来源仍 `pdf-source`，原 PDF、清单、双快照、源、块映射、golden、资源走既有身份。物化头登记 pdf_formula_contract / 清单引用；拆包显式 `--project-context` 引用已有 source_record，包头保存合同与上下文。缺 / 错来源、声明冲突不搜索邻文件或回退普通扫描。

完整准入后按真实包范围切片及所需依赖形成短期视图，同一核验核心用于源 / 译、片段、恢复 / 合并及当前交付；不从片段本身制造确认集合。原子保护数学组、表格、代码 / 链接叶子、算法、题注及脚注依赖，不跨单元切包。译文仍独立读类型、表达式、式号、顺序、角色和可确定所属，句义连接交人工复核，不以翻译字数或源绝对位置猜锚点。

请求导出从 translation record 的当前就绪投影取得确认事实，逐章分配，空数学章是空列表而不是未提供。按第 10 节渲染 / 独立核验 / 逐式目检，额外译注须具体批准及独立投影，不混入来源数学。

## 6. 共同扫描、文本与标题

### 6.1 同一定界事实

`scan_math(text, source_context=…)` 返回有序 spans 及 issues；跨度保存 kind、expr、raw、字符区间和行号，值来自原输入切片。`scan_math_spans` 仅为同一定义的投影。授予资格的调用不能丢弃 issues。

先代码感知等长掩蔽（长 / 波浪围栏及行内代码），再按偏移和当前状态消费定界，不先抢全局双美元。行内先闭一个美元，后一个可开启下一式；闭合后数字不否定。块级支持 `$$…$$` 及家族既有 `\[…\]`，只匹配自己的闭合，内部单美元属于内容。完整合法数字开头 `$5$` / `$5 + x$` 保留，无法成式的纯金额排除；`$5 + x` / `$$5 + x` 等非纯金额候选不能静默当货币。未知定界定位 issue，默认行内不跨行吞正文。

普通比较保留既有块级首尾排版空白、真实表格竖线、一致历史包装及逐项获准译注；LaTeXML / PDF 确认数学只剥已确认包装、逐字比较，不全文 `_norm_math`、拍平类型或推代数等价。安全拆包、原生对账、四族译文、恢复 / 合并和适用导出用同一事实。

### 6.2 源字面、生成语法和阅读事实

源文本节点按阅读语义转义反斜线、字面强调定界及会触发标题的位置；代码 / 数学保护后，才生成链接、围栏和数学语法。不在已序列化整串上再加写，不对已阅读标题 / 标签重复剥括号或粗体。尾部内容性 `#` 保留，`C#` 不误当关闭标记。

链接标签的数学按共享扫描保护。完整 Markdown 链接的语法转义不能先当 `\[…\]` 消耗内部美元；源 DOM 的字面括号与生成链接语法区分，必要语境恢复 / 等长掩蔽只在对应角色边界使用。保护按原偏移切片，不以第二美元正则、字符数量例外或两侧相同归一冒充保真。代码与链接的角色及精确内容继续由第 3 节独立事实核验。

`heading_entries` 以 markdown-it 实际块解析读取列零、列表、缩进续行、引用和复合容器，排除围栏 / 缩进代码，保留 H7/H8 扩展。普通文字不生成伪标题，真实标题不因管道或与注释同名而过滤；片段不误套整篇 H1 唯一性。

### 6.3 官方原题文件与工作清单

`--official-headings-file` 由共享选项助手提取，真实家族参数保持角色。文件 UTF-8 按行去排版边缘空白、忽略空行、保留内部字符及重复项，不解析注释 / 编号 / 层级。路径在实际调用基点加载：独立 CLI 为 cwd，交付复验为交付根；有效内容和文件身份进入既有检查事实。

| 家族 | 原参数角色及组合 |
| --- | --- |
| 单页 | 译文 / 源文后的逐项官方原题，与文件互斥 |
| 参考 | 后续位置为强 token，可与官方文件并存 |
| 分页 | 有序源路径不变，官方原题按实际装配范围核对 |
| API | manifest、页面 TOC、site root、源路径仍必需；标题文件不替代页面集合 / 顺序 |

显式空路径、缺值、重复声明、缺文件、不可读、坏编码、空清单均失败，不能真值判断降级。原题文件只证明有序原题，层级由原生及源译检查证明；PDF 权威仍为清单。`export_heading_list.py` 复用围栏感知事实、不覆盖输入、未闭合围栏报错；结果是工作清单，不能自证官方完整。

## 7. 强 token、术语及数字

### 7.1 同一强 token 清单

`count_token` 保留普通完整词与纯符号字面计数，点修饰段允许指令链但拒绝右续字符及小数冒充，寄存器以 `%` 为组成部分且后接字段允许、长名不充数。大小写 / 字面不改，词法命中不宣称 ISA 合法。少于源硬失败、多于源告警；源为零逐项未检查，未配置沿用 diffs=None，各汇总传播告警。

`--strong-token-file` 可重复，非空行一个 token、去边缘空白、`#` 非注释。与逐项及真实 token 位置参数按首次出现去重，绑定用同一实际集合确定性表示；合法空文件不覆盖配置，`--strong-token --use_fast_math` 是一个字面值。缺值 / 空值 / 不可读失败，等价文件布局不改变资格。

`extract_token_candidates.py --preset ptx / isa` 只在显式代码 / 指令语境输出有限候选、位置 / 片段 / 当前源摘要及未覆盖范围；人工逐项处置后实际清单进入任务及所有消费者。不得自动按 URL / 厂商启用，预设不是术语库。

### 7.2 术语只读读取

目标列有限别名包含 `中文译法/保留`、`直译`，映射同一 chinese 角色，原头 / 行 / 列作为来源元信息，不改变“英文原词 + 语境”身份。必要角色须唯一匹配；重复英文列不能因查找返回 None 被当无英文表跳过，即便重复列值相同也歧义。真正无英文原词角色的普通表继续跳过。

分列保留空格位及实际行宽，每可识别数据行进入 records 或 errors / count，缺值 / 未知方式 / 歧义按文件行定位；不交付静默子集。项目覆盖、显式共享库、语境裁决及既有保留策略不变，`直译` 只是表头别名，不推导处理方式；读取不改输入或共享库。

### 7.3 数字差异与现有复核消费

五族显式 `--numeric-review` 及可选 `--numeric-policy`。同一提取器读取当前包 / 有序完整范围，保留原数值、正负 / 小数 / 指数 / 千位 / 百分号、有限单位 / 数量级及宿主位置；代码 / 数学单列为受硬保护事实，标识符左邻先判，正文紧附单位再按支持词典识别，不扩展自然语言单位平台。

报告位置清单及差异多重集，同值异单位有提示，同 token 换所属可能无差异。项目约定只作为路径 / 内容 / 范围的身份，不执行成换算规则；无文件时明确采用“保留原值、报告差异、不自动判换算”，要按其他已确认项目口径关闭差异必须显式引用。每个差异 ID 来自本次源译角色、范围、原值、出现序及位置，不承担跨版本永久状态。

主 Agent 修译重跑，或在既有 review.items 按目标 / 类别 / 次数覆盖当前合法差异，note 记录原值 / 位置 / 口径 / 依据。脚本不解析 note 证明换算正确；历史 ID、note-only、非 closed、无当前绑定或未覆盖拒绝。包 numeric.disposed / unresolved 与最终 semantic.items 各自消费，零差异不免语义复核，未启用明确未检查。

## 9. 目录与显式批次

### 9.1 官方条目到实际目标

`build_toc --manifest --output` 的 official_basis / scope 和有序 entries 保存官方原题、编号、层级、范围及唯一译文标题出现；不从译文或文件名反推官方范围。共用消费者的有限 `heading_targets`，不启动浏览器 / 图片内联 / 高亮，仅加载所需解析扩展；缺依赖明确报错，不回退近似 slug。

### 9.2 当前逐项核验与报告隔离

批次 manifest 明确 project、record、evidence_dir、scope、mode 和可选状态说明，以参数数组逐项目调用 `verify_delivery`，不用新完成判据或自由 shell。translation / pdf / translation+pdf 只执行其模式；状态表仅提示，无可信调度且无产物为状态不明。

## 10. 真实 PDF 消费与独立成品核验

### 10.1 来源确认与渲染序

translation+pdf 从当前 translation record 就绪投影取得来源，独立 LaTeXML 导出显式传依据，不搜索相邻文件。单 / 多依据按实际章分配已确认序列，章内逐字对齐；未耗尽、耗尽后仍有数学或缺章都失败。目录不消费正文确认序列，保留适用扫描上下文；空确认列表仍核额外数学，区别于 None。

`render_ordered_confirmed` 复用同一 footnote 插件投影供导出游标、check_math、check_math_consumption 使用。正文按源序，引用的脚注定义按首次引用序移章末，定义内部保持原序、类型、表达式与所属；数量门禁仍覆盖未引用定义，不改为多重集。来源身份与源坐标不改成渲染坐标。

公式内部 `[^…]` 不能作真实引用：用同一 source_context 的共享扫描等长掩蔽非空白字符，再读脚注结构，全部缩进、空白行、换行和偏移保持。只保留长度 / 换行而擦掉缩进，或把整式改空行，都会改变定义归属，不能恢复为成功路径。

### 10.2 成品事实与视觉边界

导出保留原表达式、包装、来源类型及 source_constrained 条目，KaTeX 渲染错误或漂移拒绝替换。独立核验重读当前 Markdown / 来源及真实 PDF；数学绘字证据复用已声明 pypdf visitor，只有含非空白字符的 KaTeX 绘字可计，字体资源或布局合成换行不算。读取不可用明确失败，不引入必装 PyMuPDF 作为导出依赖；既有视觉辅助仍按需探测。

代码按 tagged PDF 实际结构、MCID 与绘字序列定位具体实例，保留块 / 行内角色、精确源内容与所属。悬空 MCID 的实际文本也纳入候选，不因结构树没有归属而漏掉插字；合法脚注序号与代码内容区分，漏行 / 改字 / 重排仍以实际损伤拒绝，不信更新后的报告摘要。视觉折行和跨页由既有结构 / 几何事实解释，不能借重复文本从别章取行。

混合矢量 / 位图的宽度核验从原输入独立枚举真正位图出现，对应成品位图绘制序，不能用全部图片序号直接索引 `/Image`。无法量测的矢量宽度不借旁边位图通过；SVG 资源 / 溢出及视觉职责保持。行内数学无字形支柱与负补偿成对处理，不缩字、裁切或放宽溢出门禁。

机器绘字存在不证明每个运算符、矩阵格或行完整；逐式原页 / 成品目检检查编号、分式、矩阵、多行、截断、角色与所属，缺口保持待视觉复核。纯翻译不强制打印，不可渲染命令不删改换角色求通过。

## 11. 依赖身份、写入与清理

复用 `compute_delivery_identity`、`expected_review_binding` 和发布前同一身份复算。来源、范围、当前文件 / 资源、真实参数 / 口径、有限检查器依赖按目标实际覆盖投影；标题文件有效内容、适配器、数字口径、PDF 提取环境和实际脚注插件版本均在适用身份。PDF 环境包含 mdit-py-plugins，普通 HTML 环境投影不因无关插件版本变化失效；未配置术语的交付不绑定术语脚本。

保护输入由现有来源声明及依赖事实枚举，不靠手写部分路径或扫描整棵项目树。原快照 / PDF、只读依据、双快照、清单、golden、默认块 / 图片映射、资源及 SVG/CSS、真实参数文件、规则、所有源 / 目标包和历史引用按各入口实际用途保护；局部资格不缩小全量写保护。

解析 / 物化先生成候选并独立对账，全部实际产物（含派生尺寸映射）冲突检查后同组发布。暂存 / 备份 / 替换失败恢复旧成员、撤销本轮新成员，诊断区分恢复 / 撤销 / 未动。不能只保护两条主文件或只回滚原先存在的成员。

最终交付仍独立运行真实来源及各模式检查，人工 source-reconcile / semantic / 适用 visual 按当前 binding 闭合。旧证据只读保留，不补新摘要追认 closed。清理遵循基础合同，保留来源、确认 / 转换、包、资源、当前及历史有效证据、恢复输入；交付图片映射仍为 `export/images_display.json`，不扩交付根清单。归位后阅读 / 恢复及适用导出输入由真实消费者复验。

## 13. 兼容性与能力边界

- 公共家族、既有位置参数、单依据旧格式、清单 version=1、旧人工 PDF 及无目录独立导出保持；已声明新来源 / 确认数学而缺输入或冲突拒绝，不静默回退。原生来源表示不互相冒充。
- 检查口径、精确区间 / 阅读事实及局部身份纠正使此前错误 PASS 失败；受影响旧记录须实际重核，不能按新 ID / 摘要自动迁移。局部事实归一不忽略组、标签、资源或公共口径变化。
- 默认跨行字面公式不自动登记，已确认 MathML / PDF 多行不受该边界限制；无可用原 TeX 的 MathML 未解决。复杂 MathML 全篇真实样本有限；KaTeX 不支持命令硬失败。
- PTX/ISA、数字 / 单位、PDF 候选均有限识别，不承诺穷举 / 自动语义。机器数学绘字证据有限，视觉及人工确认继续必需。SVG 外部 CSS 呈现、独立矢量宽度量测及非已验收阅读器锚点仍有基础合同边界。
- 未扩展的普通文本中段反斜线、根域 URL 标准化、标签字面反引号及内联脚注等既有路径不借整理改变。具体启用来源的精确角色合同仍适用，不能用这些旧边界给新路径豁免。
- 不新增 OCR、自动公式恢复 / 代数证明、任意字形替换、第二权威通道、状态 / 审计平台、自动行号迁移、自动重派、产品版本或发版。只读外部项目及历史证据不因本次整理重写。
