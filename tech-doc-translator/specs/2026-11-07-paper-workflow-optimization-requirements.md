## 1. 用户结果与范围

下一次处理同类论文时，使用者不必重新编写已验证的通用适配、重复猜测输入合同、反复整篇导出、手抄核验条目，或重新诊断已有记录的问题。合法输入能沿正常流程完成；失败能定位原因；没有相关事实变化的工作可按证据复用，相关事实变化只触发必要的重核。

本次覆盖经验文档中的全部独立问题与正面复用经验，不只选三个高收益项。按共同目标合并重复叙述，同时保留各自场景、来源、优先级和验收。P0/P1/P2 表示风险与收益排序，不表示低优先级已被排除或推迟；后续若缩小实施范围须另行确认。

必须同时实现两类结果：减少无效墙钟等待与全链路返工；减少重复操作和上下文消耗。不能用费用下降掩盖耗时增加，也不能用耗时下降掩盖质量退化。历史费用和预测节省用于排序，不作为已实现收益。

本文组织已批准的需求，配套设计另见对应文档。批准确定目标行为，不表示现行实现已改变或验收已完成；迁移外部翻译项目、发布版本或调整模型与计费时段不在本需求范围内。

## 2. 基线与质量边界

### 2.1 现有能力与已知缺口

| 领域 | 已有能力及本轮依据 | 优化边界 |
| --- | --- | --- |
| 来源与数学 | 现行论文规格要求独立原生来源对账，原 TeX 精确保留；PDF 走勘察、原页裁决、物化、独立对账 | 修合法输入误判、保真与定位缺口；不让生成器替自己证明完整 |
| 翻译就绪与交付 | `verify_pdf.py` 的 `run_verification` 调用翻译就绪；`verify_delivery.py` 的 `check_translation_readiness` 接受 `translation+pdf`，再把完整检查集合交给 `rerun_checks`，其中可再次调用 PDF 核验 | 静态确认递归闭环存在；本轮未复现其具体耗时，不直接指定双记录为最终设计 |
| 输入范围 | 就绪检查要求实际有序输入等于记录 `inputs`，每个输入均须有翻译家族检查覆盖 | 静态确认目录角色缺口；不能扩大为任意附加文件免检 |
| 复核身份 | `expected_review_binding` 已包含适用来源、资源、检查、环境及目标，并排除复核正文和本次生成报告 | 复用现有身份模型；O.7 的漂移根因仍未确定，不声称已证实核验改写报告 |
| 清理与重用 | 现行合同要求持久证据、直接阅读、重新导出及恢复；临时 `work-dir` 不应成为永久状态 | 解决证据可持续消费，不用永久保留整个临时目录代替清理 |
| 既有优化 | CUDA/Sphinx 优化已有源结构、表格映射、依赖预检与定位能力 | 按实际适用性复用；本轮论文场景另立需求，不重建一套通用基础设施 |

代码基线入口：[翻译就绪与交付核验](../skills/tech-doc-translator/scripts/verify_delivery.py)、[PDF 核验](../skills/tech-doc-translator/scripts/verify_pdf.py)、[PDF 导出](../skills/tech-doc-translator/scripts/export_pdf.py)。除上表已静态确认的事项外，经验中的缺陷表现均标为历史观察；设计时须核对当前入口及可复现样本，不按旧行号直接打补丁。

### 2.2 必须保留的保障

1. 来源、版本、范围、资源和转换依据可回查；原始快照、PDF、交付 Markdown 及资源不能被隐式改写以迎合检查。
2. 来源独立对账、确定性硬检查、语义复核和适用的视觉 / 链接复核职责保留。两个核验能发现不同错误时，不以“重复”为由删除其中一个。
3. 相关内容、规则、检查器、环境或依赖变化使旧复核失效；未知影响范围不得默认无影响。更新摘要、复制旧 PASS、重建记录不等于重新核验。
4. 普通翻译并导出仍经过 `--translation-record` 就绪门禁；不能改成独立导出模式绕过递归或覆盖不足。既有仅导出模式保持其独立用途。
5. 公式内容、类型、出现序、所属，表格格位与分组，图片身份、尺寸及链接目标保持。减少操作不能以漏项、整类豁免或静默角色转换实现。
6. 失败保留旧有效产物及证据；清理继续保护直接阅读、重新导出与恢复依赖。质量缺口明确阻断相应完成认定，不能仅写进交付说明便算通过。

## 3. 功能需求

### R1 有限终止、进度与重复执行控制（P0）

来源：§2.1–2.2、§6、M.1、M.5。

- 合法的翻译就绪、PDF 核验与最终交付调用必须有限终止，不因记录含 PDF 检查而递归重入。非法循环依赖须尽早给出可定位失败，不能表现为长期无输出。
- `verify_delivery`、`verify_pdf_source`、`export_pdf` 及其昂贵核验阶段默认输出可及时读取的阶段进度，包含当前操作、对象或检查序号、开始 / 完成 / 失败；兼容既有机器结果输出。执行者能区分仍在推进、重复回到同一阶段与等待外部条件，不能只凭进程存在判断正常。
- 相同事实下无必要的重复计算应消除；必要独立核验仍保留。复用条件、失效条件和本次实际执行项可查，失败后无需无依据地从头重跑全部环节。
- 长时间无推进时应暴露当前阶段及停止 / 诊断依据，避免盲目长轮询；不把历史 PID 周期、某篇运行时长或统一三分钟上限硬编码为所有任务的正常标准。

### R2 前置预检与可定位诊断（P1）

来源：§2.5、§3.x、§4.2–4.4、§5.2–5.4、M.1、O.1/O.5。

- 在昂贵解析、裁决或打印前暴露当前源家族可判断的结构、资源、环境、输入角色和导出条件缺口。普通翻译不因未启用的 PDF 可选依赖失败。
- 版本与口径检查给出清单记录值、当前值、实际解释器和处理方向；版本不符不能只重写清单绕过回源。记录生成、导出与核验采用一致的实际环境，或按已确认变化完成必要重核，不固定历史 PyMuPDF 版本为通用要求。
- 结构对账至少定位首处源 / 目标差异及文件、块 / 行 / 页或表格坐标，列出期望和实际角色、内容或数学位置；图片缺失给出实际解析基点和候选路径。已有详细诊断复用，不另建平行报告体系。
- 经验中的“下标变空格且同段公式失保护”“两个不相干表头被合并”等指纹可辅助定位，但不能未经核对就断定根因。修补后先确认实际落点、唯一性与运行入口，避免重复追查并不存在的缓存问题。

### R3 LaTeXML 常见结构一次正确处理（P1）

来源：§3.1–3.4、§5.3、§7.3、O.1。

- 支持有明确资源身份的 `<object>` 图片、有序列表、H1 中出版注及普通段落文本软换行；保留列表序号 / 嵌套、图片身份 / 尺寸 / ID、注文本及其顺序，不以删除节点或把有序列表无条件展平成段落求通过。
- 出版注不污染题名，也不被拆成多个无意义段落。原题确有公式或链接时，中文总标题投影仍保持其技术含义和目标；先区分出版注与真正题名内容，不能用删除公式、链接或改写 Markdown 回避投影问题。
- 普通段落软换行不制造额外正文块；代码和预格式内容不套普通文本空白规则。含内部换行的合法 `alttext` 不使同段其他公式失去保护，原 TeX 空白与换行仍按现行精确合同保存。
- 如需派生快照或结构规范化，保留原始输入、逐处变换和身份对应；除可见文本外，还核对结构、数学、链接、资源及所属。可见文本折空白后相同不能单独证明全部保真。

### R4 锚点与内部链接直接可用（P1）

来源：§3.6、§7.3 第4项、O.2–O.3。

- 解析与翻译流程提供可复用的目标清单，覆盖段落、图表、单元格和参考文献；按实际对象保持 ID 与位置，不逐篇手写或依赖首个同名文本猜测。
- 段落锚点不得制造空段并把紧邻标题孤立在页底；单元格锚点不得增加表格数据行。采用空锚点能力时遵循现有消费者支持范围，不把 `<br>`、`<span style>` 等未经支持的 HTML 当作排版手段。
- 保留源参考文献的 Cited-by 回链及各次出现，并确保目标存在；同作者同年份不同字母后缀不能撞键。参考家族不能因不适用的通用锚点对比而被要求删掉必要目标。
- 最终 PDF 的每条适用内部链接均到正确对象；链接数或目的地数相等只作辅助，不能代替目标关系和实际导航验证。

### R5 复杂表格映射可靠、避免布局返工（P1）

来源：§3.5、§7.3 第5项、O.4–O.5。

- 复用既有显式转换与逐格核验合同，减少手工计算跨度、格位和重复映射。全部源格、空位、表头、分组、代码、数学及链接均有对应；源跨度与实际列数矛盾时定位并显式裁决，不自动补值或删列。
- 映射目标表序号以最终输出全部表的全局顺序为准，包含简单表；不相邻复杂表不能误并到同一目标。快照或输出结构变化后，受影响映射须失效或重建并核验。
- 跨行 / 跨列的展示须保留分组含义；经验中的“跨列只占锚点列、跨行重复值”是已使用方案，不直接替代所有表的角色与格位要求。
- 区分数据列固有宽度压力与映射把长分组文字挤入首列造成的压力。允许忠实、无信息损失的表述调整，但不能反复缩写引文、删除单位或改变数据含义来试凑列宽；最终阅读要求见 R11。

### R6 PDF 裁决与物化减少重复且不静默错配（P0：错配防护；P1：辅助效率）

来源：M.2–M.3、M.6，§4.2。

- 方括号引文、类别、标签和编号按原页真实角色输出，不能因 Markdown 转义而误识别为展示数学；不把全部匹配方括号的文字强制改成数学来绕过扫描问题。
- ACM 双栏 run-in 标题与同行正文按真实阅读边界分开；跨行题名及编号 / 题名分行能形成正确标题，不产生孤段。字形全覆盖不能掩盖正文归错块。
- 结构变化后符号、引文、公式的注入仍指向原内容与正确出现；位置序号漂移不能把 `[8]` 静默替成箭头。重复字面值也须消歧，不能仅把位置键换成同样不唯一的文本键。
- 在物化前尽早发现字形遗漏、重复和边界问题；字形审计不替代语义、角色与顺序核对。结构变换后直接抽查物化结果的对应关系，机器全绿不能替代该检查。
- 原页区域图、字形坐标以及已确认同版本的 LaTeX 材料可辅助公式裁决，减少反复目测；PDF 原页继续是本路线权威，不引入必须下载源包或第二套权威来源。

### R7 已确认源层与机械装配复用（P1）

来源：§4.2、§7.1–7.3、O.6、O.8。

- 同版本、同 PDF 身份且适用范围 / 环境明确的裁决清单、源 Markdown、块映射、快照、golden 与资源可复用；保留复用来源和改动字段，不修改供体项目。路径调整后独立重跑当前源对账，不能仅凭同摘要继承全部资格。
- 缺资产、源版本变化或裁决不适用时定位差异，只重做受影响部分；不得丢弃已有有效裁决后从零制作整套源层。
- 提供可复用的数学占位与逐字装配做法，拒绝漏项、重复、乱序、错类型及错所属。现有精确公式顺序合同保持；中文语序调整须通过句式组织保留源序，不为了流畅静默交换两式。
- 译写前明确图表、题注、正文与列表的相对结构约束：不合并被图表打断的段落，不把源中标题前的表移到标题后，不把两条列表项之间的图移到整个列表之后。合法结构直接通过，确有移位时给出具体差异，避免写完后多轮试错。
- 题注中英回显遵循现行规则：强 token 多出保持告警口径，不为凑计数返工；回显不得引入无来源的额外数学或破坏原题注语义。

### R8 管理字段、资源与投影检查一致（P1）

来源：§4.1、§4.3–4.4、§5.2、§3.1。

- 合规章首来源 / 日期等管理块中的链接与行内代码不冒充论文正文的 leaf host。判定范围与既有管理字段投影一致；正文同名字段、任意首块和未确认非原文内容不能被连带排除。
- 合法译注投影后，PDF 提取的折行或断词不应误报正文缺失；真实删除、替换、串段仍须检出，不采用全文去空白或跨对象拼接来掩盖差异。
- 明确源 Markdown、交付 Markdown及映射各自的资源基点；正常流程不要求用户靠试错发现并复制第二套图片。可复用显式映射或受控定位，歧义和同名异图不能静默回退命中。
- SVG 等资源能否满足当前显示与尺寸核验，应在打印前告知并给出保真路径。必要派生位图须保留原件、来源关系、转换依据、清晰度和显示尺寸；不把“5倍 / 2380px”或“所有图必须位图”推广为所有来源的固定标准。

### R9 目录输入不再被翻译覆盖误挡（P1）

来源：§2.3、§6、§8.4。

- 单篇及合订的显式目录可进入记录驱动导出，不要求它伪装成翻译正文或补一条虚假的翻译检查。翻译内容仍完整覆盖，导出有序范围、来源与目录身份可核对。
- 目录需按其职责验证内容、官方顺序、目标、页码与实际导航；只标记 `toc` 不能让夹带的未核验正文免检。
- 面向用户的交付说明、术语表、前置说明或样式文件不因目录例外自动成为正文输入。既有输入角色保持；额外扩展另列需求，不将“任意附加输入均放行”作为本条含义。

### R10 导出与核验消费同一上下文（P1）

来源：§5.4、§2.5、§7.3。

- 导出已使用的来源适配 / 确认数学等依据，在后续核验中默认可从可验证证据取得，不要求重复手填相同参数；多来源、多篇的依据集合保持完整。
- 缺失、陈旧、不可读或显式参数冲突须定位拒绝，不能用自动继承隐藏问题。导出报告提供定位信息，不替代独立核验对当前来源、输入和依据的读取。
- 记录、导出和核验的示例与模板采用同一口径，不再让执行者逐篇推导参数组合。最终流程不要求维护内容重复且必须人工同步的多套事实。

### R11 打印版心、公式与表格可读性（P0：整篇缩印；P1：局部布局）

来源：§5.1、§5.5–5.7、O.2/O.4。

- 打印前按真实打印版心检查溢出；宽公式、表格或其他块不得触发整篇缩印。失败定位源块及实际 / 可用宽度，不把整体缩放只报成多张图片尺寸错误。
- 原页确认的多行公式保持实际多行 / 对齐关系，式号与公式同页且不叠字；渲染转换不能改权威 TeX 或核验基准。裸换行可能只是 TeX 排版空白，不能无条件全部改为数学换行。
- 表格数值、正负号、百分号及关联单位可明确连续识读，表头不产生误读；兼顾长引文列和分组行压力。仅在说明中写“接受折行”不足以证明质量，须以实际成品判断是否仍可准确阅读。
- 图块移页造成留白时能解释约束；可改善的排版在尺寸保真、图题所属、可读性及图内内容完整前提下优化。不能为填满页面自动缩小来源有明确尺寸的图或任意拆图；不可避免的留白可保留并说明。
- 不承诺固定页数、统一版心像素值或统一字号；正文、页码、代码、目录、脚注和链接的既有成品合同继续适用。

### R12 数字复核去噪与去录入重复（P2）

来源：§2.4、§8.5。

- 标题 / 交叉引用、管理元数据、单位换算和双语回显等有上下文的提示可分类、归并展示，保留每个原值、位置、当前 ID 与未处置项，不能靠删差异达到“少于十条”。
- 工具自动准备条目和已实际作出裁决的记录，减少手抄几十个 ID；共同依据可复用，但每个当前差异仍有明确处置，新增或变更项不能被旧批量决定带过。
- 单位换算或语义等价仍由实际回源复核确认，不因工具能重算 ID 就自动闭合 NUM。真实数字 / 单位错误及无法解释的提示不能因去噪消失；零差异仍不等于语义正确。

### R13 交付记录、证据与清理稳定（P1）

来源：§2.6、§6、§7.3、O.7。

- 当前交付所需报告、依据和调用上下文可持久消费，清理临时 `work-dir` 后仍能回查与按合同复验；不靠永久保留全部临时输出维持可用。
- 正常核验不应自己制造下一次核验的身份漂移。重复核验、清理已确认无关的渲染图片或归位证据后，能说明哪些事实改变、哪些复核仍有效、哪些须重核。
- 真实依赖变化仍使相关绑定失效；不能仅重建 binding 并重复运行到通过。O.7 保留为待定位场景，不把“连续两次通过”增加为每次交付的常规步骤。
- 记录生成减少重复抄写，双记录可作为现状规避经验，但最终记录形式留待设计重审。共享事实、翻译就绪与最终 PDF 交付的职责不应互相递归或人工重复维护。
- 旧证据批次按当前索引、历史回查和恢复用途判断；只有确认无用且新交付有效才可清理。“未被当前索引引用”不足以单独授权删除历史依据。

### R14 有证据的复核复用（P1，新增兼容规则已批准）

来源：§7.4、M.4、O.7。

- 已完成逐页视觉复核的版本，若相关事实未变，应能避免重复全页目检；由像素等价支持的复用须关联旧实际复核、当前 PDF、相同完整页面范围及明确渲染条件。条件和证据不足时仍做实际复核。
- 页数、逐页文本和书签条数相等只能作为初筛，不能证明图片、公式、位置、裁切和布局等价。PDF 字节一致也不能替代完整上下文检查。
- 视觉等价不授予链接语义、来源或语义复核资格；链接注解、目标及受影响导航独立核验，不能因像素不变直接续签全部复核。
- 少量页面拼图可减少读图调用，但全部页面内容仍须看清，不能以缩小导致细节不可辨代替逐页覆盖。视觉疑点用文本层及局部高清图交叉确认，文本提取正确不自动否定实际重叠、裁切或间距问题。
- 本条会改变现行清理后全部页面再次视觉检查的执行方式，已随本需求获批；实现并通过验收前，实际交付仍沿用现行合同，不先用历史像素比较案例作为一般豁免。

### R15 经验、模板与轻量执行成为默认可用能力（P1）

来源：§7.3/7.5、§8.4、§9、M.1/M.5、O.0。

- 开始同类任务前完整扫描当前项目及同目录姊妹项目已有的交付说明、优化经验和踩坑记录，读取相关问题与有效规避；只读交付结果不能替代读取过程教训。超过十分钟的卡住 / 反复失败，先回看相邻经验再继续诊断；不扩大成全知识库扫描。
- 把已验证的通用结构处理、锚点 / 表格映射、数学装配、记录生成及环境 / 参数示例纳入组件已有入口或配套资料，执行者无需逐篇从零拼脚本。模板保留必要核验，不复制项目路径、论文编号或历史摘要。
- 临时规范化与产品默认能力的职责明确；已被组件吸收的项目补丁不再作为每个新项目的必需步骤。仍需项目裁决的差异、工具限制与规避写入交付说明，后续可定位复用。
- 单篇能直接处理时不新增工作包体系；按实际篇幅、结构和并行需要使用现有能力，不硬编码“30页”阈值。无 root 栈采样等历史排障技巧保留为按需资料，不加入常规执行链。
- 工具输出优先呈现支撑当前判断的内容与定位，避免反复回传未变的长报告或已核实页面；必要来源阅读、上下文和全页复核覆盖不因此减少。
- 不为默认需要的进度、定位和正确处理新增必须手工启用的开关；也不为消除重复另建通用调度、状态平台或第二套质量规则。

### R16 用实际收益核对优化结果（P2）

来源：§1、§8、§10。

- 区分必要工作、缺陷返工、等待用户 / 外部条件、模型传输重试与复盘本身；分别记录重复解析 / 导出 / 核验次数、人工补录量、墙钟和可得的 usage 费用，不将它们相加成重复计费。
- 比较固定来源、范围、质量要求和可说明的环境条件。R/T/H 的历史费用是原文记录，返工占比和约43%节省是原文估计，本轮未重审原始日志；M/O 费用未知，不补造数字，也不要求优化后仍落入旧返工占比区间。
- 通过目标场景证明相应重复已消除，同时检查质量及必要核验未减少；若总时间或费用无下降，解释剩余成本，不只展示个别步骤变快。
- 复用已有计量与报告工具，按需复盘，不把每次全量成本分析增加为交付门禁。错峰计价、宿主推理档位和模型选型只记为外部优化机会，不自动安排任务延迟或调整模型。
