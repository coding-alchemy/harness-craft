## 1. 用户结果与范围

用户可以把论文翻译经验用于当前 Skill：原始论文的正文、数学、代码、图表与脚注完整进入翻译输入；合法输入可处理，确定损伤可定位拒绝；任务上下文、逐包复核、目录和批次核对可以复用，最终完成依据当前文件及实际复核。

确定性脚本负责提取、表示、独立对账和硬检查；主 Agent 负责来源、范围、术语、语义与视觉裁决。机器通过、源译计数相等、文件齐全、子 Agent 完成回报及历史 PASS 都不代替这些职责。仅翻译任务不强制新增永久 PDF，也不要求操作特定阅读软件。

本文按现行能力统一原 R1–R11，并将原五期本地 R1–R5 编为 R12.1–R12.5。原分期是实施顺序，现行行为只有本文及对应设计一组正文；需求、兼容性和验收强度保持。

## 2. 需求依据

需求来自既有翻译资料与当前代码的对照，而非照搬旧 Skill 的成功记录。确认过的缺口包括：MathML 的原 TeX 丢失；相邻及数字邻接公式漏扫；PTX 修饰符漏计；普通 `#` 被写成标题；推荐术语表别名不可读；逐项目重复拼装任务、证据和目录；PDF 提取将多行、分式、上下标展平，或因没有美元定界误报“公式 0/0”。

保留的 LaTeXML 论文及 Kimi、Janus、Gemini、BytePS 等 PDF 原页说明：式号齐全不证明公式完整，图内矩阵不能替代正文矩阵验收，代码表达式也不自动成为正文数学。旧脚本的命中率、固定字形偏移、站点政策、模糊锚点和按旧行号回填只作线索，不成为通用默认、授权或验收事实。

## 3. 公共合同

1. **来源只读、身份与范围明确。** 原始快照 / PDF、版本、选区、资源和取得依据可回查；解析只读本地输入。不确定来源、版本或范围时停止相应处理，不自动换最新版、其他来源或另一版本 PDF。
2. **独立来源对账先于分派。** 原生来源和实际 Markdown 分别读取，逐项证明内容、顺序、角色、所属及精确出现。生成器的对应、缓存、摘要和统计只供核对，不能制造独立预期；共同遗漏不能由源译一致掩盖。
3. **结构转换逐项说明。** 代码、数学、标题、图片、脚注、表格和强 token 的硬检查保持。具体来源位置与实际目标转换可核验，不提供父范围、表行或整类免检。
4. **候选、裁决和资格分开。** PDF 沿用勘察 → 原页裁决 → 物化 → 独立对账。候选为空不证明无内容；机器 basis、`resolved`、删除 pending / stale 或改摘要不授予权威、分派或完成资格。
5. **复核绑定当前事实。** 相关源、译文、资源、转换、规则、检查器或环境变化使旧复核失效；须实际重核后恢复，不补签历史 PASS。全源准入后，无关有效包按局部事实复验复用；未知影响范围报告待复核，不默认重译。
6. **写权限与失败保旧。** 子 Agent 只写唯一译文目标。辅助工具只写明确输出；不覆盖来源、清单、规则、他包或依赖。发布失败恢复旧成员并撤销本次新成员，旧有效产物、证据和索引保持。
7. **人工与机器分层。** 计数、数字提示、硬检查、来源全量对账、语义复核和适用的 PDF 视觉复核分别说明结果。程序不能证明人工记录是否真实回源，也不能自动证明所有数学或译文语义。
8. **交付与清理可复用。** 项目术语优先；共享库及预设显式选择。最终按实际模式运行当前交付核验；验收后清理仍保护来源、工作包、清单、转换、资源和恢复证据，归位后引用及真实消费者可用。

## 4. 功能需求

### R1：LaTeXML 原始来源、内容与资源保真

- **R1.1 身份。** 规范转换接入现有参考家族，保留题名、论文 ID、实际版本、最终 URL、取得时间、原始摘要和资源结果。主 Agent 用独立确认资料核对实际内容，不只信文件名、H1 或请求 ID；身份错配、失败与回退显式暴露。辅助获取可选，不扩大网络能力。
- **R1.2 数学。** 实体解码后的 `alttext` TeX、行内 / 展示类型、顺序、公式组和式号保持；`<`、`&`、竖线、命令、首尾空白及换行逐字保留。无可用 TeX 或类型冲突逐项未解决，不删除、不猜写、不留内部标记。字面数学按共享识别边界登记，原节点确认的多行行内数学按限定上下文处理。
- **R1.3 内容和所属。** 正文、直属文字、标题、图 / 子图、题注、表格、算法、列表、参考文献、清单及脚注保持有序内容与关系。代码保留角色及精确空白，链接保留真实角色、标签与目标；图片拆段不盲拼两边文字。脚注保留引用 / 定义及段落、列表、表格、代码的原序和层级。展示公式不随宿主改为行内。
- **R1.4 独立出现。** 从原始 DOM 独立建立到实际输出的逐项对应，包含非数学节点。等数换内容、同内容换身份、共同漏项、区间互换、改类型 / 式号 / 顺序 / 所属、额外输出和无解释重复均阻断分派。合并、展开、去重及装饰排除须有具体依据；渲染错误不能整类删除，同号异图不能按编号合并。
- **R1.5 表格和资源。** 简单表及逐表映射的复杂表逐格保留跨度、空值、代码、链接与数学；脚注表使用相同门禁。优先可核验的 HTML / SVG，资源每次出现和尺寸可查，同名异资源不覆盖。必要 PDF 替换须确认同版本、原页区域、裁剪、图内文字 / 图例及视觉依据；版本不明不替换、不放行缺图。SVG/CSS 子依赖参与核验。
- **R1.6 消费与论文口径。** 选区及多快照各有依据、范围和资源基点，按声明源序覆盖；原始快照进入来源链、工作包与最终交付。题注使用现有中英格式，官方编号和交叉引用保持；References 默认英文，项目可覆盖；名称与首现服从项目术语。提取伪影保留原值、依据及处置，确定损伤不能靠说明完成。

### R2：共享数学识别、比较与未解决诊断

- 相邻 `$…$$…$` 是两个行内出现；闭合美元后紧邻数字不漏扫。保留类型、原表达式、顺序与位置，不吞公式之间正文。货币、转义美元、围栏和行内代码排除；非纯金额的未闭合候选定位为 issue，不能静默忽略。
- 普通 Markdown 行内默认不跨行；已独立确认来源的多行行内公式仅在限定上下文识别，贯通源 / 译、拆包、恢复 / 合并和导出，不把换行改块级或折空白。
- 普通家族保留既有块级首尾排版空白、真实表格竖线转义、一致历史包装告警及显式获准译注的逐项规则；原 TeX / 确认 TeX 使用精确合同，不套普通容差。不做代数等价，也不让译注遮蔽源公式。
- 所有授予资格的消费者处理同一跨度及 issues；拆包不切公式及必要结构，未知定界阻断分派、导出就绪和完整核验。

### R3：显式强 token、文件与有限候选

- 正文与代码同一计数语义，完整识别普通词、点分修饰符和 `%` 寄存器；`.rn` 不由 `.rni` 满足，`%tid` 不由 `%tidy` 满足，小数和词缀不冒充指令段。遗漏真实命中失败；增加项沿用告警；源中缺席的每个配置项明确“未检查”，空清单明确“未配置”。
- 逐项参数、该家族既有 token 位置参数和可重复的 UTF-8 文件清单合并去重；等价输入使用同一实际清单和绑定。保留其他位置参数角色，`--use_fast_math` 等以 `--` 开头的合法字面值可用；缺值、空 token、缺文件或坏编码明确失败，合法空文件不能清空其他配置。
- PTX / ISA 预设须显式选择，只从明确代码 / 指令语境输出有限形态、实际源位置和未覆盖语法。主 Agent 逐项接受、拒绝或待定，保存候选到实际清单的关系；不从厂商、URL 或文件名自动启用，不影响术语策略，不开放任意规则引擎。
- 任务、证据、恢复 / 合并与最终核验使用同一已裁决清单；PDF 使用现有裁决清单的强 token 通道。只有改变实际检查口径的差异才撤资格，等价写法或重复行不制造新语义。

### R4：真实标题与 Markdown 阅读保真

- 普通段落、表格、列表、引用及代码注释的 `#` 保持原角色，真实标题保留层级、顺序和内容性字符（如管道、尾部 `#`、反斜线、星号）。阅读文字、生成语法、代码和数学不互相二次解释；不按与注释同名等文本特征排除真实标题。
- 四类 HTML 检查支持独立确认的 UTF-8 官方原题文件：每行一项、忽略空行、保留内部字符 / `#` / 重复项，不设注释语法。仅与同角色的逐项官方原题互斥；源路径、强 token 和 API 页面 TOC 的角色保持。空路径、缺值、重复声明、缺文件、坏编码或空清单失败，不降级为未提供。
- 官方基准可发现源译共同删标题。导出标题工作清单排除长反引号 / 波浪围栏及代码，未闭合围栏诊断；导出物不能反过来证明自身官方完整性。H7/H8、中文后缀、分页层级转换、片段及 H1 约束沿既有范围处理。PDF 权威仍来自原页裁决，不增平行标题入口。

### R5：数字与单位定位及人工处置

单页、分页、参考、API/DSL 和文字 PDF 的包范围及最终确认范围均可显式启用数字辅助，报告数字、百分比、数量级及单位的原值、位置和差异次数。`5ms→5s` 有差异，`TPUv3s` / `Model5ms` 不冒充正文数量；不能可靠识别的形式明示未检查。

提示不自动换算、改文或判断语义等价；`104 billion→1040 亿`、双语题注重复可按项目口径逐项回源说明。同 token 换归属可能无统计差异，零差异仍须语义复核。当前差异须在现有复核记录逐项处置，历史 ID、note-only 或其他目标记录不能代闭；输入、相关资源、检查器或口径变化须重核。统计解释不覆盖任何硬失败。

### R6：逐包实际复核与资格

从当前源、策略和完整预期生成待复核证据，不从实收译文数推范围。核对唯一源 / 目标、范围、正文及两侧资源、真实检查器、强 token 和适用口径，缺摘要不以空值相等通过。

硬检查通过只产生 pending。主 Agent 对当前包实际独立回源、逐项登记且无未解决项后才能完成；无全局 done 或自检代替路径。恢复与合并重新读当前事实，缺包、末片、额外、重复、异源、错目标、硬损伤和失效证据分别拒绝；合并后仍全量复验。相关变化失效、无关有效包复用及发布保旧遵守第 3 节。

### R7：自足任务与任务变化

每包任务具备四要素：可访问的项目指令 / 规则 / 项目术语及适用样例；唯一只读源与可写目标、源序 / 范围 / 摘要；模板与特殊输出合同；脚本实际计数、自检入口和返回要求。`[TABLE]` 等解析标记如何转为真实译文须明确，不与残留检查冲突。

无主会话的执行者能定位当前解释器、Skill 和输入，只写唯一目标，返回新术语首现、原文 / 解析问题、实际检查与不确定项。四要素缺失、路径不可读、源未对账或规则冲突不能分派；不手填计数支配源文，不固定安装路径、模型、重试或并发。

源或规则变化先暂停受影响旧任务的完成认定，展示精确前后差异；缺旧文本只报依据缺口，不从摘要猜内容。旧回报、已读消息不证明同步，结果经当前复验 / 实际重核后才可复用；不自动迁移、覆盖或重派。

### R8：PDF 候选、原页裁决与再勘察

- 每项候选有当前 PDF 身份、范围、页 / 区域、原值、实际参数、适用条件、依据及歧义；坐标空间、旋转和 pt 单位明确，同号或同字不合并出现。无法定位、无候选或边界冲突均如实报告。
- **图区：** 单图、上下 / 并排、无大外框、同号图和图内伪表格均可定位；标签、图例、题注和紧邻正文所属须回页裁决。裁剪仍逐图目检、核对资源及尺寸，不靠扩框闭合。
- **表格：** 提供二维格位、空位、多行表头、跨度与边界歧义，供人工转录；不自动生成权威表格，不以展平词数证明移列 / 漏格未发生。
- **顺序：** 提供单栏、双栏、跨栏块与双快照差异；最终顺序由原页裁决，跨栏图不切成两栏，互换块不能凭字数相等通过。
- **字符：** 保留码位、区域、上下文、原值和有依据的建议，区分提取缺陷与原文异常；无依据不 ASCII 化或套固定偏移。裁决值与必要译注落实；代码 golden 固化前确认、固化后逐字节核验，不能刷新摘要保留旧复核。
- 同源再勘察保留人工分类、块、排除理由、口径及顺序，刷新不自动恢复资格。源 / 范围 / 区域 / 口径变化保留旧依据及新增 / 消失项，无有效重核不得删 stale 追认。未处理素材及 pending 继续阻断完整交付；正式数学走 R12。

### R9：只读术语表兼容与逐行诊断

`中文译法/保留`、`直译` 与规范目标列等价，原表头 / 行 / 列可回查且不改原表；`直译` 不推导处理方式。项目覆盖、英文原词 + 语境身份、显式共享选择和来源语义保持，不补缺值、不猜译法、不导入项目词库。

已识别表的必需角色未知或歧义均报错，包括重复英文列及内容相同的重复目标列。每个可识别数据行恰为有效记录或有文件 / 行号 / 原因的错误；普通无英文原词角色的表不误收，不能静默吞表、猜首列或交付缺行子集。

### R10：官方范围目录及实际导航

按独立确认的官方顺序、范围、原题和编号对应最终译文，生成独立 `00_目录.md`；单篇、多章及局部范围可用，局部只链接已交付内容并说明范围。同名章、同章重复标题、中文标点、连续连字符、显式锚点与围栏伪标题按实际消费者处理，不按文件名或首个同名标题猜目标。

链接基于目录实际位置、相对路径及正确片段，换 cwd 仍能使用；不修改章节、资源或区间外用户说明。真实阅读器导航及适用的 PDF 目标 / 页码 / 点击须验收，不承诺所有阅读器兼容。翻译默认独立目录，用户可明确不要；已有无目录 Markdown 仅导出时不强制补建。

### R11：显式批次与当前交付留痕

只处理显式项目清单，分别按 `translation`、`pdf`、`translation+pdf` 调用当前交付核验。定位缺文件、硬失败、复核缺口、过期及状态矛盾；无产物且无可信调度依据为“状态不明”，不推断未分派或重派。仅 PDF 不强加英文源，翻译不强加 PDF，范围外项目不扫描。

单项目记录、编码、来源集合或成员损坏只使本项失败，合法同伴完成且报告完整；仍保护可解析的声明和依赖。重复 / 歧义项目、模式 / 范围矛盾和输出冲突保持整批拒绝。报告写入不覆盖输入、资源子依赖或历史证据，发布前重核当前引用，漂移结果标过期。

后续修源、口径变化或补译在已有说明 / 证据中记录日期、变化位置与前后内容、依据及重新验收；历史与当前可分别回查。批次成功不触发失败 / 暂停项目清理，不删除历史及恢复资产。

### R12：PDF 确认数学物化与独立消费

- **R12.1 原页确认。** 编号 / 未编号、行内 / 展示数学均按每次出现定位，保留原提取字形、公式簇、上下文、式号线索和不确定项。主 Agent 全范围原页确认内容、结构、角色、位置与阅读序；机器漏候选可人工补登记。图内数学随完整图，代码随 golden；普通编号、货币、代码美元不自动成为数学。
- **R12.2 表示与唯一位置。** 按确认事实物化符号、分式、上下标、定界、多行 / 对齐关系、正文矩阵和公式组；式号独立绑定，不入表达式或合并同号出现。PDF 没有原 TeX 时不伪造逐字原文基准，确认 TeX 是有原页依据的表示转换。重复锚点消歧后才写出，不用同文本首次匹配、式号排序或旧行号定位。损伤不能靠空白归一、控制字符清理或降级声明放行。
- **R12.3 独立来源。** 重读原 PDF、当前人工确认及实际 Markdown，核对每次内容、类型、式号、结构、位置、角色与所属；可靠文本层直接重读，提取缺陷由具体原页依据补足。共同漏式、等数换式、换 ID / 区间、重复插式、移格 / 换行列及前后正文损伤拒绝。修改候选摘要或区间不绕过真实损伤；修改确认事实须重新实际回源，程序不冒称证明人工真实性。
- **R12.4 译文与包。** 同一事实贯通源译、拆包、片段核验、复核、恢复 / 合并和当前交付。公式组及必要的格位、算法、题注和脚注依赖不被切开；空确认集合、表行或父范围不免检。源物化的正文连接独立比较，译文的句义连接由语义复核负责，不新增中英文逐字相等硬检。补式后重建受影响包 / 映射并实际重译或重核，无关包按公共合同复用。
- **R12.5 真实 PDF。** 明确请求导出时经过当前翻译就绪、真实导出、独立成品核验及逐式目检。保持类型、式号、矩阵 / 多行关系、表格和脚注所属；合法脚注移位按实际渲染投影接受。漏式、错型、额外数学、缺章、空绑定章额外数学或漏渲染按目标原因拒绝并保旧。字体 / 报告数量不能证明每式完整绘出，不可渲染表达明确失败，不删命令或改角色求通过。

## 6. 兼容、限制与非目标

普通四类 HTML、既有位置参数、人工 PDF 路径、无目录独立导出和单依据旧格式行为保持。新来源或确认数学已声明而缺参数 / 字段、声明冲突或未知版本时明确拒绝，不降级。规则、来源、记录及真实依赖身份变化须按实际影响重核旧证据；不默认整篇重译或批量迁移存量项目。

已知边界：跨行字面公式默认不自动登记，区别于已确认 MathML / PDF 多行原 TeX；复杂 MathML 真实全篇样本有限，组合由持久测试补足。KaTeX 不支持命令导出硬失败。数字 / 单位及 PTX/ISA 只提供有限语法，候选不穷举；PDF 字体证据不能证明逐式完整。目录仅确认已验收阅读器的锚点兼容；SVG 外部 CSS 呈现、不可独立量测的矢量宽度仍有既有边界。普通文本旧反斜线、根域 URL 标准化及标签字面反引号等未扩展路径保持既有口径，不借组织整合新增豁免或承诺。

不纳入：OCR / 扫描版公式识别、新位图自动提取、自动 TeX 恢复、代数等价、通用字形修复、第二权威来源、LaTeX 源包构建、站点绕过；通用 IR / 规则引擎 / 状态库 / 调度平台、全局 done、自动语义评分、固定模型 / 并发 / 重试、LLM 共享词库；按行迁移译文、自动重派 / 覆盖、清空未完成资产及未经明确授权的发版。
