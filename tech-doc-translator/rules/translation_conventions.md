# 技术文档翻译约定（Practice-first）

> 沉淀自真实 NVIDIA/Sphinx 类网页翻译实践。项目自身 `术语表.md` 与本约定冲突时，以项目术语表为准。

## 1. 源确认

- 动笔前 `curl -sIL <url>` 检查重定向链与版本号，记录落地 URL、版本和抓取日期。
- 抓取后的本地 HTML/PDF 为翻译唯一原文依据，不凭模型记忆补写。
- 章节范围以官方 TOC/导航为准；存在两种会改变交付内容的合理解释时先请用户裁决，不自行扩大或缩小范围。
- 每次换文档或复用解析器，分派前都要把原始源中的标题、图片、`<pre>`、块级公式和脚注等关键结构与解析产物做总量和顺序对账；未识别块级结构必须显式暴露，禁止静默丢弃。

## 2. 术语处理

1. **首现标注，后文可纯中文**：有通用中文定名的术语，如 线程块（thread block）、网格（grid）。
2. **保留英文不译**：社区惯用英文，如 kernel、warp、tile、cubin、fatbin、PTX、SM、bank、stream。
3. **一律不译**：代码、API/函数名、产品名（cuBLAS、NVCC、NVRTC）、版本号（sm_120）、数学公式。

项目内 `术语表.md` 为权威；没有时由主 Agent 创建最小 Markdown 表。

## 3. 固定转换规则

| 原文元素 | 译文处理 |
|---|---|
| 标题 | `# 1. English Title（中文标题）`；保留官方英文原题与编号 |
| 脚注 `[1]` | `[^1]`，注文全译 |
| Note / Warning / Important | `> **注（Note）**` 等引用块 |
| 图题 Figure N | `**图 N. 中文（English original）**` |
| 交叉引用 "see Section X" | 保留官方节号，不造链接 |
| 英文习语 | 中文意译 + 首现附英文，如 锁步（lock step）|
| 商标 ® / ™ | 原样保留 |

标题中的大小写、标点、弯引号和其他内容性字符也属于原题，必须逐字保留；纯 API/选项名标题可以不加中文后缀。

复杂表格允许根据官方页面重建列结构，但不得改变单元格含义。跨列表头需展平时保留分组关系；承载“不支持/不适用”等含义的空单元格统一写为 `—`，并保留原表说明或加必要译注。

## 4. 行文底线

- 复杂长句可拆分，但不改变逻辑关系。
- 代码围栏、标识符、命令、选项、路径逐字保留。
- 代码密集文档不得手工转写围栏内容；从源文程序化提取/回填，并在译后和合并后按顺序逐块比对。围栏数量相等不能替代内容一致。
- 源文段内硬换行先还原为完整句段再翻译，不逐行制造破碎短句。
- 疑似原文错误先回源确认；技术性误导照录，可加 `【译注：原文如此，疑为笔误】`。
- 官方重复内容保留，不替换成“参见第 X 章”。
- 只有在源文本程序化比对确认一致时，才可逐字沿用既有译文；存在差异的部分必须重新翻译并记录。

## 5. 交付形态

- 文件头部含 `> **原文** / **来源** / **译例说明**` 引用块。
- 多页文档文末附官方目录；单页可省略。
- 图片下载到 `images/`，不热链外站；按全书/全站建立图片顺序与身份映射，跨章复用同一资源，无官方图号的图片不得占用 `figure_NN` 名称。
- 暗/亮图片对只嵌入一个可读版本，并在译例说明中记录取舍；最终按 Markdown 所在目录检查相对路径，以文件魔数或 `file` 判断图片有效性，不依赖扩展名。
- 合并文件是新的交付产物。合并只做围栏感知的拼接和标题调整，禁止对全文执行不感知围栏的空白压缩或格式化。

## 6. 校验与裁决

- 硬不变量至少包括：标题数量与顺序、H1 约束、代码围栏配对及逐块内容、公式、图片顺序/存在性/有效性、脚注配对，以及项目指定的强 token。任一失败均不得交付。
- 表格、列表、段落和“语义块总数”会因合法重建发生漂移。漂移是必须逐小节定位和解释的告警，不能仅凭正负方向直接判丢失，也不能忽略后判通过。
- token 多重集适合定位标识符遗漏，字母多重集只适合作为解析损失兜底；二者都不证明顺序、结构或语义正确。
- 结构校验通过后仍须回到权威源复核数字与单位、否定与条件范围、指代与交叉引用、术语首现。翻译 Agent 的现象上报可作为线索，原文错误或解析器缺陷的技术定性由主 Agent 回源确认。
- 校验脚本也是待验证的软件：遇到 FAIL 先定位是产物问题还是口径问题；修改脚本后用已知正确产物回归，再按完整输入口径验证新产物。
- 任何内容、术语、合并或校验脚本修复都构成新的出错面；修复后重跑受影响检查，最终合并产物必须完整重验。
