# 变更日志

按产品版本记录主要功能、兼容性变化与已知限制。

## V1.3 — 2026-10-01

- **文字版 PDF 翻译**：新增源勘察、文本提取、代码核对与矢量图裁剪，接入译文检查和 PDF 交付流程。PDF 源依赖单独安装；扫描或混合 PDF 仍需取得宿主 OCR 授权。
- **解析与翻译保真**：四类 HTML 解析器保留代码、公式、表格、列表、脚注和链接的内容与顺序；新增独立源文对账，阻断遗漏、替换、乱序和重复。译文检查加强标题、脚注、代码空白、公式及项目指定关键 token 的核对。
- **拆包、恢复与合并**：按完整结构拆包并保留引用依赖，源文可逐字节还原；恢复时补验并复用有效译文，源文或资源变化会使旧复核失效。合并拒绝缺包、重复和错配，失败保留原成品。
- **图片与离线资源**：新增四类源共用的尺寸回补工具，可从源高度推导宽度；快照完整时离线复用，补抓须显式启用。图片及 SVG/CSS 子资源按来源身份核对，换图或依据冲突时拒绝且保留旧映射。PDF 导出增加尺寸覆盖与解码预算预检、严格尺寸模式，以及大尺寸 PNG/JPEG 的嵌入重采样。
- **交付留痕**：新增 `verify_delivery.py`，统一核对交付范围、资源、检查记录和实际复核证据，覆盖分篇 PDF。交付级图片映射固定为 `export/images_display.json`；证据持久保存，发布失败保留上一份有效记录。机器通过后仍须完成语义与全页视觉复核。
- **PDF 排版**：默认中文总标题、连续页码和正文两端对齐；前置出处及已标识译注从打印视图排除，出处保留在报告中，额外排除须显式声明，代码与原文引用中的译注字面量保留。修复宽表缩印、长 token 溢出、数学环境渲染和代码行距；短代码块整块保留，长块按完整行分页，无法容纳的短块拒绝导出。加强目录、链接与逐块代码核验，兼容 Chromium 134/153 的结构树输出。
- **升级影响**：最低 Python 版本为 3.10；新增 `tinycss2`、`Pillow`，PDF 可选依赖新增 `uniseg`。旧图片记录缺少来源证明时须重新解析或补验；排版、检查口径或绑定依赖变化后，旧成品须重新导出核验，旧复核证据不得直接沿用。解析产物落入系统临时目录时告警。
- **已知限制**：PDF 源翻译仅完成单篇样本验证，不自动提取位图素材与公式；代码缩进重建依赖等宽字体。SVG 的 `xml-stylesheet` 尚不支持并阻断通过。真实 CUDA 13.4 样例中 368/794 个代码块丢失源行首缩进，经用户接受为本次交付限制，后续仍需修复。历史 PDF 不符合当前排版政策时，`--translation-record` 的就绪复核会先因旧成品核验失败而拒绝重导出，本版本尚无政策迁移入口。
- **验收记录**：torch.fx PDF 样本、cuSPARSE 拆包恢复流程及 CUDA 13.4 六章合订（554 页、11 图、17 张复杂表）完成验收；CUDA 的语义、视觉复核及所发现内容与格式问题已闭合，上述缩进限制保留。七组既有回归已验收；本次发布复验在 Chromium 134/153 下各通过 619 项测试、84 个子测试及完整 PDF 集成回归。

详细合同：[PDF 源翻译](skills/tech-doc-translator/references/pdf_source.md)、[PDF 导出与交付](skills/tech-doc-translator/references/pdf_export.md)、[图片尺寸映射](skills/tech-doc-translator/references/images_display.md)。

## V1.2 — 2026-09-12

- 新增独立 `00_目录.md` 与 PDF 印刷目录，支持章级或一级节目录，自动回填实际页码并核对链接目的地。
- 修复章首管理字段与目录导航的排除规则，保留代码、技术说明和混合容器中的正文；多章合订意图不明时先询问，术语表默认不导出。
- 新增图片显示尺寸链路：解析留存、合并绑定、导出应用，核验器独立测量 PDF 中每次图片的实际宽度。
- 核验器独立重建目录和正文预期，检出错误排除、目录重复、页码篡改及链接目的地交换；修复代码跨页引起的核验误报。
- 验收记录：CUDA 六章合订（372 页、67 图）两种目录模式完成机器、视觉与链接复核，10 套回归通过。该样例缺少同版本源快照，图片未恢复源尺寸，按自然尺寸与版心上限导出。

## V1.1 — 2026-09-09

- 新增译文 Markdown 的单篇与合订 PDF 导出，保留标题、表格、提示块、代码、公式和图片，中文正文可检索、可复制。
- 新增独立 PDF 核验器，检查内容覆盖、代码、资源身份、链接、大纲与命名目标；缺图、坏目标或不支持的公式等失败不覆盖已有 PDF。
- 随包提供 KaTeX、打印样式与中文字体策略，渲染拦截外部网络；普通翻译与 PDF 导出依赖分离。
- 验收记录：真实 cuBLASLt、Best Practices 单篇与 NVCC 合订完成机器及全页视觉复核，对抗样例覆盖输入顺序、图片身份、重复内容与坏链接。

## V1.0 — 2026-08-30

- 支持显式选择多个共享 Markdown 术语库，优先级为项目术语表、先声明的共享库；统一解析表头、处理方式与来源，拒绝静默漏列。
- 发布由 12 份已验收术语表整理的 NVIDIA 术语库，保留首现中英、后续中文或英文/缩写等处理规则；`leading dimension` 默认译为“前导维度”，cuSPARSE 项目保留英文；来源回流去重。
- 验收记录：四类源家族、工作包与共享术语库回归通过，cuSPARSE 前三章的独立及合并译文保持项目术语口径。
