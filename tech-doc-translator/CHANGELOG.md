# 变更日志

本文件按版本倒序记录技术文档翻译器已经完成验收的产品行为。

## V1.2 — 2026-09-12

- 章首管理字段投影改为按 Markdown 块结构与源行位置识别（导出器与核验器两侧独立实现同构规则）：管理引用块以家族标签字段段（原文/译例说明/来源/抓取日期）开头，字段边界在引用段落内按行确定，无标签段落/列表行是真正延续（含 CommonMark lazy 续行），围栏、缩进代码与嵌套引用是技术内容并终止延续；首个非家族内容（正文、列表、表格、缩进代码、Note 等其他标签引用块）即正文边界。引用块内嵌套围栏（四反引号包三反引号示例、带尾文的闭合候选、波浪号）、缩进代码中的字段字面量与正文后的同名引用块不再误删。
- 目录导航消费只针对已确认的导航片段：纯导航容器（行/项内除章链接外只有章编号、标题、文件名等导航元数据）整体移除，混合容器（同一行/项内的技术说明、注记）只解除导航链接、内容保留；层级列表按“编号+标题/标题对应本书结构”逐条确认消费。目录链接片段无法消解（含分篇与其他坏目标）在消费前以 FAIL 阻断；含节模式下指向普通锚点的片段同样阻断，不猜测。`--toc-sections` 并入指向二级标题的可消解节链接（章首 H1 与更深层 H3+ 折叠），引用式链接与百分号编码锚点按目标身份规范化。分篇导出时范围外章节的纯导航行随消费一并移除（链接仍按待处置报告；混合说明与裸链接只解除链接），核验器独立复现同一消费并断言范围外条目不再出现在印刷目录页。
- 核验器预期与导出器解耦：独立重建目录条目（inline+引用式链接、编码锚点、节层级门控）、用自己的导航消费实现建立“PDF 应包含哪些目录正文”的预期（不再调用导出器的消费函数）；错误内容即使被同步写进导出证据也由内容/代码核验检出。目录链接注解按“页序+自上而下”与条目逐位绑定，交换目的地而标题/页码/目标页集合不变也会失败；条目标题可跨任意多行识别；“标题+页码”邻接计数判定目录重复，保留散文中的合法标题重复。
- 导出开始前明确选择与默认排除：多章合订意图不明时先询问；`00_目录.md` 与 `术语表.md` 不计入章节数；术语表默认不进 PDF，正文指向术语表的链接用 `--unlink-target` 转纯文本并记录；各章章首“原文”“译例说明”模板字段连同续行默认投影排除，“来源”“抓取日期”等独立字段保留（导出器记录排除区间，核验器独立按行核对，代码围栏内同名文字不受影响）。
- 目录文件按显式目录角色交付：翻译合订默认生成独立 `00_目录.md`（章级导航 + 官方层级对照），替换“多页文档文末附官方目录”的旧约定；无目录输入不强制创建。
- 图片显示尺寸链路：四个解析器在输出旁写 `<stem>.images_display.json`（出现序、内联 CSS 宽度、百分比参照、无法判定项分离记录）；`merge_api.py --display-src` 按资源身份与全局出现序绑定为交付级 `images_display.json`（含 sha256）；导出器 `--images-display` 校验摘要与出现序后注入受限宽度（版心上限兜底），同名 Markdown 按完整相对路径绑定，文件名兜底仅在唯一命中时允许、歧义即 FAIL；核验器独立解析 PDF 内容流（q/cm/Do 与 CTM）测量实际绘制宽度逐张对账（容差 0.75pt）。契约见 `references/images_display.md`。
- 印刷目录：`00_目录.md` 的导航内容合成为 PDF 前置目录，默认章级、`--toc-sections` 加一级节（章名兼容“N. 标题”前缀与“第 N 章”中缀两种风格；同一章的节/片段链接默认折叠为章级条目，含节模式下可消解的节链接与纯文本层级列表同源并入）；条目点线引导、页码右对齐且为含目录偏移的 PDF 实际页序；两遍打印（探测回填，最多 3 次未收敛即 FAIL）；层级列表只消费编号或标题能对上本书结构的导航条目，其余说明条目与说明列表保留，被消费的导航表格/列表连同空表头壳与悬空引导句一并移除；核验器独立重建条目预期并逐条核对可见页码、链接注解目的地与目标标题所在页。
- 章首字段投影围栏感知：引用块内的代码围栏是技术内容，围栏内的字段字面量与闭合围栏不参与排除；围栏闭合须同字符且不短于开启围栏（嵌套示例围栏不误闭合），容忍 `> >` 嵌套引用前缀；导出器与核验器按同构规则独立扫描。
- 打印样式修复：`pre` 跨页断行改为整块避免，消除跨页代码与同页表格文本提取交错的核验误报（超长代码块仍会不可避免地分页）。
- 验收：真实 CUDA 编程指南六章合订（372 页、67 图、36 命名目的地）章级与一级节两种目录模式均 2 次打印收敛、机器核验通过；全部页面拼版扫描与密集页（目录/图示/公式/宽表/章界）放大复核通过；44 个内部链接注解全部解析、目录条目点击目的地全部正确。多页印刷目录收敛（63 条目录跨 2 页）与同名 Markdown 映射消歧由合成回归覆盖。已记录缺口：真实样本无同版本源快照，67 张图按自然尺寸与版心上限导出（“未恢复源尺寸”），属设计已批准的取舍边界。
- 固定用例验收：H01–H12 章首结构用例与 T01–T16 目录用例全绿；N01–N04 负向注入（说明/代码字面量缺失、目的地交换、页码篡改）全部由语义检查检出；P01 真实 CUDA 样例（第 3 章单篇 39 页 + 六章合订 372 页两种目录模式）机器核验、372 页全页拼版扫描、密集页放大与链接注解证据（0 断链）通过；P02 合成压力样例（247 页、123 条跨 3 页目录、超长标题跨行、同名章消歧 86/167、三位数页码）两种模式通过。回归矩阵 10 套件全过。

## V1.1 — 2026-09-09

- 新增已有译文 Markdown 的 PDF 导出：单篇导出与跨章合订共用一个入口（`export_pdf.py`），输入顺序即文档顺序；逐章解析保留标题、表格、提示块、代码原文与历史数学包装（`$\(...\)$`、`$\[...\]$`），图片按来源身份内联去重，中文正文可检索可复制。
- 新增独立 PDF 核验器（`verify_pdf.py`）：以原始输入重建预期，核对输入与资源摘要保护、逐章标题顺序、文本与代码覆盖、内部链接目标、外链保留、PDF 大纲与命名目标；原始扫描与解析层计数交叉核对。
- 导出离线可复现：KaTeX 0.18.7 裁剪版（仅 woff2，含 LICENSE 与 NOTICE）与默认 A4 打印样式随 Skill 分发（`assets/pdf/`）；渲染阶段拦截全部外部网络请求；中文字体链仅使用验证过 ToUnicode 干净的字体（STFangsong/STHeiti/Arial Unicode MS），避免康熙部首码位破坏检索。
- 失败闭环：缺图、坏内部目标、重复输入路径、输出指向输入、不支持的公式（KaTeX 错误）均定位到具体输入与原因后判 FAIL；失败候选不覆盖已有成功 PDF；范围外本地文档链接显式报告，处置方式由用户确认。
- Skill 入口区分翻译与导出模式：仅有译文直接导出；翻译加 PDF 在 Markdown 验收后进入同一导出流程；普通翻译不安装 PDF 依赖（`requirements-pdf.txt` 与翻译依赖分离）。PDF 规则集中于 `references/pdf_export.md`。
- 验收：真实 cuBLASLt 第 3 章（110 个公式、39 页）、Best Practices 第 10 章（14 张图、22 页）单篇与真实 NVCC 第 2、3 章合订通过机器检查与全部页面视觉复核；对抗样例覆盖逆字典序输入、同名不同内容图片、重复标题/脚注/引用定义、跨章链接、坏目标、重复与缺失输入。已验证依赖组合：Python 3.12、markdown-it-py 3.0、mdit-py-plugins 0.6、Pygments 2.20、Playwright 1.51（Chromium 133）、pypdf 6.16。

## V1.0 — 2026-08-30

- 支持显式选择一个或多个 Markdown 共享术语库，并按“项目术语表高于共享库、先声明的共享库优先”生成源文相关术语子集。
- 增加共享 Markdown 术语解析层，整合与选择命令统一识别多表格、合法表头变体、处理方式和来源列表；未知术语列不再被静默跳过。
- 发布由 12 份已验收项目术语表整理的 NVIDIA 术语库；源表中的 `译` 统一为“首现中英，后文中文”，首现译后使用英文或缩写的词条保留对应行为。
- NVIDIA 默认使用“前导维度”，cuSPARSE 项目对 `leading dimension` 的保留英文口径通过真实第三章源文覆盖验收；来源回流重复执行不会继续增加重复来源。
- 单页、分页、数学与深层嵌套参考手册、多页面 API、工作包和共享术语库回归全部通过；cuSPARSE 前三章独立章节与合并产物保持项目术语口径。
