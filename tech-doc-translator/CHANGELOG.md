# 变更日志

按产品版本记录主要功能、兼容性变化与已知限制。

## V1.4 — 2026-10-24（正式版更新）

- CUDA/Sphinx 数学解析保护公式内部空格与标点，只转换一对最外层定界；独立源对账保留内部定界并排除行内代码。
- 单页 API 可使用完整家族核验；有序 / 无序列表按真实 Markdown 读取信息计数，标题工作清单复用现有导出入口。
- API 保留链接图片及原目标、富引用 / 分组脚注 / 图例 / details 和两类 Sphinx 标签页的块顺序与父属；标签及其面板进入独立有序对账，未知富容器明确定位。PDF保留列表内原始围栏代码及父项归属，首标题为H2时印刷目录不重复同一目标。
- 简单表格按实际格位及格内硬不变量核验，拒绝缺行、伪行和格代码错绑；v2表头依据原DOM、映射及实际来源范围贯通翻译和精确转换，不从Markdown加粗推断角色，v1人工表示及td强调保持兼容；正式v2交付必须实际消费匹配当前来源、快照、映射及范围的项目/导航上下文，缺失或错配明确拒绝。中间包显式使用 `--table-code-stage intermediate`；经当前复核的合并以 `--finalize-table-code` 转为可读格位说明，最终 Markdown/PDF 拒绝实际解析标记。旧包须按当前检查身份重核。
- API 可显式展开可解释的 rowspan / colspan，生成 GFM 与绑定快照的 v2 表映射，保留头分组、空覆盖及格代码原点；配套文件只发布新位置。单快照映射接入现有全源准入及局部资格，无关表事实不因新映射文件路径变化而失效，v1 人工转换语义保持。
- 多快照来源按自身表映射及声明区间独立对账，局部表号不累加；旧声明须唯一归属，两级冲突及跨快照重复消费拒绝，局部资格保留其他快照有效包。
- API 保留可定位的源对象锚点，合章可用现有来源记录证明页到章归属并转换稳定命名空间；最终核验重建链接对象关系。PDF 裸片段仅查本章，旧跨章回退须据源改为明确文件目标。
- 规则 / 术语变化沿用实际选区、任务差异及逐包当前资格；历史任务声明的只读引用受同一输出保护。CUDA 同构样例区分词义语境、保留空格位，技术疑误与排版注分开处理。
- 工作包合并使用最终目录暂存、flush/fsync、独立重读核验和单文件原子替换；候选、写入或替换失败保持旧成品，首次失败不留下最终文件。
- PDF 译注剩余文字核验使用原 Markdown 独立删除区间及整章脚注上下文，兼容命名 / 数字 / 重复引用，保留同行正文与代码字面记法；真实正文或脚注缺损仍拒绝。
- PDF 导出在内联 / 打印前检查候选核验依赖和实际 Chromium 能力，位图 / 脚注 / 视觉辅助按实际模式检查并报告解释器与隔离安装入口；缺库不再伪装为图片尺寸未知，失败保持旧成品。
- 图片回补入口可用重复的 `--compose-map` 组合原位章映射，完整重定位文档与图片引用，回源核对出现及尺寸；覆盖包含零条目的声明文档，输出保护所引用的来源/交付文件及资源依赖，API章映射顶层与条目使用一致相对基点。重复 / 错图 / 漏图拒绝，未确定项不变，候选重读后原子发布。
- 已授权的子 Agent 翻译任务遇新停滞 / 限流事件自动减半并发上限，保留冷却、用户暂停和唯一写者约束；真实宿主已验证状态读取、确认终止和单写者接续；受控事件验证实际减并发/去重/停止补派及冷却，真实冷却观察超过60秒。自然限流/停滞未实测，长窗口使用标注的受控时间，按用户批准口径完成验收。
- CUDA优化按修订标准验收完成：52页独立来源对账、七包当前资格与六页代表性交付有效，正文/PDF身份保持并复用原阅读点击证据；不是全书重译或旧609页PDF验收。持久证据见现行[需求](specs/2026-10-23-cuda-practice-optimization-requirements.md#10-当前验收结论2026-10-24)。

## V1.4 — 2026-10-15（正式版）

- **论文翻译保真与交付**：
  - 支持 LaTeXML 原始快照与文字版 PDF 的来源闭环，保留正文、公式、图表、脚注、代码和链接；独立对账拒绝遗漏、错绑及结构损伤。
  - PDF 提供图区、格位、阅读顺序和字符线索；原页确认的数学可保真物化并贯通翻译、工作包及真实 PDF 导出。
  - 加强公式、标题、强 token 和术语表核验，提供显式 token 文件 / 候选及数字、单位差异定位。
  - 生成自足任务、逐包待复核证据与可导航目录；按显式批次核对三种交付模式，支持实际重核后的局部恢复，失败保留有效产物。

  **兼容提示**：旧参数、人工 PDF 和无目录独立导出路径保持。新来源及确认数学须提供完整依据，未确认内容保持 pending；相关来源、资源、口径或检查器变化后，旧证据须实际重核，无关有效包仍可复用。工具不自动翻译、裁决、换算或迁移旧译文。

- **翻译产物收尾清理**：验收后自动清理已确认无用的产物，保留交付文件、依赖、恢复输入与证据；完成阅读、恢复及必要的 PDF 视觉复验。同步修复 PDF 内容与代码核对误报。详见[收尾清理](skills/tech-doc-translator/references/cleanup.md)。

**已知限制**：复杂 MathML 布局目前由样例测试覆盖；跨行字面公式不自动登记。KaTeX 不支持的命令导出失败，成品仍须逐式视觉复核；数字提示不证明换算或语义。目录仅确认已验收阅读器的锚点兼容；SVG 外部 CSS 呈现及无法独立量测的矢量宽度仍有限制。

## V1.3 — 2026-10-01

- 新增文字版 PDF 源翻译，支持勘察、文本提取、代码核对与矢量图裁剪，接入现有核验和交付流程。
- 加强四类 HTML 的解析与翻译保真，新增原始源独立对账；完善拆包、恢复和合并，拒绝缺包、错配及失效复核证据。
- 完善图片尺寸回补、离线资源与来源身份核对，新增严格尺寸模式和大图重采样。
- 改进 PDF 中文标题、分页、目录、代码和宽表排版；统一交付范围、资源与复核证据核验。机器通过后仍需语义和视觉复核。

**升级影响**：最低 Python 3.10；新增 `tinycss2`、`Pillow`，PDF 可选依赖新增 `uniseg`。受影响的旧图片记录、复核证据及 PDF 须重新解析或核验。

**已知限制**：PDF 源翻译仅验证单篇样本，不自动提取位图和公式；扫描或混合 PDF 需宿主 OCR 授权。代码缩进重建依赖等宽字体，已交付 CUDA 样例仍有源行首缩进缺失。SVG `xml-stylesheet` 不受支持；不符合现行排版政策的旧 PDF 尚无迁移入口，会阻断重导出。

详细说明：[PDF 源翻译](skills/tech-doc-translator/references/pdf_source.md)、[PDF 导出与交付](skills/tech-doc-translator/references/pdf_export.md)、[图片尺寸映射](skills/tech-doc-translator/references/images_display.md)。

## V1.2 — 2026-09-12
