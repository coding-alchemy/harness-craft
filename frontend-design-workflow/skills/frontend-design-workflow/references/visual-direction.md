# 视觉方向与规则

本地改编于 2026-10-16：daymade 两包、Anthropic frontend-design 与 taste 固定版本；归属和实质修改见[随包声明](../licenses/ATTRIBUTION.md)。按本次任务选节阅读，不要求填满模板。

目录：产品语境 → 参考分析 → 视觉选择与规则 → 参数示例 → 风格候选 → 参考生成候选。

## 1. 从内容与任务形成方向

确认产品解决什么问题、具体受众、使用频率、主要动作和内容范围（空、典型、极长或大量）。已有说明直接使用；仅澄清会改变决策的缺口。后台的长期阅读、品牌展示的首次印象、移动端的快速操作可以有不同密度和强调程度。

把“专业、清爽、有活力”落到选择：例如采购人员反复比较订单时，名称与金额分层、金额列对齐、状态文字稳定，比增加入场动画更直接。内容品牌页可以让产品自身的材料、形态、语言或独特场景成为首屏重点。不要仅按“金融”“科技”等行业名称决定深色与配色。

简短说明色彩策略、字体角色、布局概念及一个主要视觉重点，再对照用户约束检查。色彩可用 4–6 个具名值表达角色；已有品牌足够时直接复用。允许一套字体以不同字重形成层级，或两套有明显职责差异的字体，不必为个性替换现有系统字体。首屏可以是标题、产品图、演示或一个交互，取决于当前内容。

需要完整规划时可查原始 [shape](materials/taste/shape/original.md) 的用途、内容范围、状态、交互、约束与反目标问题，或 [brandkit](materials/taste/brandkit/original.md) 的品牌隐喻与视觉应用例子；只利用缺少的输入，不执行其强制访谈、图片产出和写入流程。

## 2. 参考图：先观察，再适配

先实际查看任务提供的图；多图先分别观察，再找重复关系与冲突。读不到图时停止图像事实判断，说明需要的材料，继续能由文本或源码支持的部分。

按画面记录：布局比例与对齐、阅读层级、可辨文字、字体形态与相对大小、主辅色关系、间距节奏、按钮与组件形态、图像处理、边框/圆角/阴影和视觉密度。提取的是可见关系，不是凭截图认定完整产品规范。

| 依据类别 | 可交付内容 | 边界 |
| --- | --- | --- |
| 可见事实 | 左侧导航、右侧主内容；标题大于正文；主操作为实心而次操作为描边 | 明确对应画面位置；不要由看不清的像素确认精确值 |
| 估算 | 主辅栏约 1:3，标题约 28px，接近某类字体，颜色近似值 | 标为估算，说明受截图缩放、压缩和设备影响；已有源码/设计文件可用于校正 |
| 补充设计 | 键盘焦点、悬停、加载/错误/禁用、移动端重排与动效 | 单张静态图没有展示时保持未知；按当前任务另设计，不能说从图中提取 |

迁移时保留自己的内容、品牌、功能与技术栈。借鉴分组、比例或层级不等于复制竞品功能、商标、文案或资产。不同参考冲突时说明本次取舍与理由；需要改变用户要求的差异先确认。用户明确指定的玻璃、纯黑、Inter 或圆角等可以使用，来源相反偏好不覆盖它。

参考太小无法可靠判断时，先请求较清楚材料或利用可得设计文件，标明剩余不确定性。有授权且环境可生成参考图时，可补充图像探索；生成内容属于新设计，不证明原截图的隐藏状态。原 [image-to-code](materials/taste/image-to-code/original.md) 的逐区检查、文本/字阶/间距/按钮提取及防漂移例子按此边界使用，不沿用“必须先生成图”和固定图数。

## 3. 规则应能指导实现

只记录当前需要的“值或关系、对象、依据”：色彩角色、文字层级/字重/行宽、组内与组间间距、组件形态、状态及响应式变化。沿用有效组件与 token，避免另建同义规范。已有页面局部任务可以简记“名称为第一层、编号次要、金额靠右；按钮沿用品牌”。

代表对象要能暴露所选规则的难点：例如长中文标题、真实金额、重复条目、主要按钮与空/错状态。先在这个对象验证，再推广其余页面；未实施时给出验证办法并保持未验证。

## 6. 参考生成候选

brandkit 的品牌隐喻可从首字母、产品动作、两概念融合、负空间或几何构成出发，原文用 3×3（或 2×3、2×2、1×3、4×2）板组织标志、构造、数字应用、短语、颜色、字体、实体应用、图像与细节；4:3/16:10 是其示例。[完整原文](materials/taste/brandkit/original.md)保留场景、配色和布局例子，**只在当前请求确有视觉探索需要时**选用，不生成无关标志或品牌提案。

imagegen-frontend-web/mobile 是参考生成来源候选：原文已取得，但本 Skill 未集成生成服务或其平台流程。详细[Web原文](materials/taste/imagegen-frontend-web/original.md)与[mobile原文](materials/taste/imagegen-frontend-mobile/original.md)在相关生成请求中按需查具体例子，强制图数与控制措辞不执行。维护清单保留固定版本和资源状态；缺图像生成能力时可独立交付文本方向与规则，生成动作保持未完成。需要生成时沿用环境已有且获授权能力，生成图不替代实际前端运行。尚未引入可选执行依赖。
