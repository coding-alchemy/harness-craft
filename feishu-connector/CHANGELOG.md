# 变更日志

本文件按版本倒序记录飞书消息连接器的功能变更。

## V1.4 — 2026-08-29

- 删除未发布的 `notify` flow；stdin 与 `prepare-shell` 恢复 `send`、`rich`、`task`、`task-auto` 四种白名单，未知 flow 在读取配置、构造客户端或联网前以退出码 `2` 失败关闭。
- 未指定正文的通知复用现有 `task`，发送任务、状态和执行结果；成功包含核心结果及相关验证，失败包含具体非敏感原因及安全下一步，待确认包含待决定事项及选项或影响。
- 首次发送前只脱敏秘密值、凭据和个人信息的具体值，保留普通项目、提交和测试信息；发送进程尚未创建的隐私拒绝且允许更安全替代时最多重写一次，网络或投递状态不明不跨进程重试。
- 保留现有 `send`、`rich`、`task`、`task-auto` 接口、配置、卡片、重试、UUID、退出码和六文件安装合同。

## V1.3 — 2026-08-23

- 新增离线 `prepare-shell`，让 Codex 的初始审批命令包含消息类型和全部动态字段；真实发送仍由现有 `send`、`rich` 与 `task` 完成。
- 复用四种 stdin 白名单、现有 parser 校验和项目根解析，使用标准库 `shlex.join()` 生成带绝对 `--project-root` 的 POSIX Shell 命令。
- 完整命令按 UTF-8 计上限为 96 KiB（98,304 字节）；超限、非 POSIX 或准备失败时不发送、不截断、不拆分、不回退不透明传参路径。
- README 与快速使用文档就近声明 POSIX Shell、macOS/Linux 验证、PowerShell/`cmd.exe` 不支持及完整命令长度口径。
- 保留现有直接 argv、非 Codex stdin、配置、卡片、重试、UUID、退出码和六文件自包含安装合同。

## V1.2 — 2026-08-16

- 更新 Agent 执行权限合同：用户明确要求发送时，在首个真实发送子命令调用上直接申请受控的沙箱外联网权限。
- Codex 在上述首次发送调用上使用 `sandbox_permissions=require_escalated`；执行器支持限制网络目标时，仅允许 `open.feishu.cn:443`。
- 不得先在网络隔离沙箱中使用发送子命令试发或探测飞书连通性；`config` 等明确不联网的诊断仍可在沙箱内执行。
- 如果联网权限被拒绝或执行器不支持权限升级，停止调用并报告消息未发送，不得退回隔离沙箱或改用其他渠道绕过审批。
- 增加文档合同测试，覆盖发送触发条件、权限参数、执行顺序、离线诊断例外和拒绝处理。
- 本版本不改变连接器 CLI、HTTP 发送与进程内重试实现。

## V1.1 — 2026-08-13

- 新增通用富文本 `rich`，以带蓝色标题和 `lark_md` 正文的 interactive 卡片发送 Markdown 内容。
- 明确消息路由：标题、分段、列表、链接或代码等格式化信息优先使用富文本，简单短句使用纯文本。
- 区分用户明确要求的显式 `task` 与仓库规则驱动的 `task --auto`；显式通知不受 `notification.autoNotify` 控制。
- stdin 入口支持 `send`、`rich`、`task`、`task-auto` 四种白名单流程，并保证与直接 argv 入口一致的消息语义。
- 明确通知结果状态：只有 `Feishu message sent` 表示已发送，自动通知关闭时报告 `skipped`，避免将成功 no-op 误判为已投递。
- 增加脱敏的网络错误分类，包括 DNS、超时、TLS、连接和不可达类别，便于区分配置问题与执行环境网络问题。
- stdin JSON 严格拒绝重复键，避免字段覆盖造成调用语义不明确。
- 补充重复通知风险说明：进程内重试复用同一 UUID，退出码 `5` 时投递状态可能不明，调用方不得跨进程重试。
- 明确用户的显式发送请求构成本次向固定接收人的外发授权；未指定正文时仅发送任务结果和必要的简短验证信息，且授权不自动延续。

## V1.0 — 2026-08-12

- 支持向已配置用户发送纯文本消息。
- 支持任务完成、任务失败和待确认三种状态的 interactive Markdown 消息卡片。
- 支持环境变量、项目 JSON 和全局 JSON 的分层配置与严格校验。
- 支持由仓库规则控制的自动通知，并在 `notification.autoNotify=false` 时跳过发送。
- 对网络错误、限流和服务端错误执行有限重试，单次逻辑发送复用 UUID 以降低重复发送风险。
- 提供敏感信息脱敏、分类退出码和安全的错误输出。
- 提供不访问真实飞书或凭据的离线测试。
- 提供可重复执行且支持冲突保护的 Skill 安装器。
