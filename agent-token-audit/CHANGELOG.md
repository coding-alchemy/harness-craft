# 变更日志

## 未发布

- **费用估算**：`report`/`overview`/`recompute` 接受用户明确加载的本地价格配置（CLI `--pricing`、网页文件选择），按源供应商＋完整模型身份与带时区生效区间精确匹配，Decimal 分项计价与摘要/分组精确累加，规范十进制保存不受默认计算精度截断，大金额仍可按两位小数显示；按币种分列已定价小计与未定价原因；费用为估算而非账单，未配置价格不影响原 token 查询。价格配置快照（含未命中规则）、逐记录计价与 v3 费用投影随报告保存在可选 `analysis` 扩展（v1 不允许扩展）。
- **性能分析**：报告保存独立入样的 TTFT、来源观测区间吞吐与工具执行耗时，各自标注事件定义、有效/缺失/冲突样本及排除原因，不改变 token 合计。ZCode 数据库来源支持 TTFT 与观测区间吞吐（终点含完成事件处理开销，非服务端纯生成速率）；Codex 逐调用 TTFT/吞吐因所核来源缺少可配对的请求起点/首 token/生成终点三元组而不可用，报告中显示来源原因。工具原生执行耗时与调度至完成跨度分列。原生 TTFT 列仅作可选交叉核验，确认零延迟与零输出正区间可正常绘制性能日图。
- **保存与复用**：原范围重算默认沿用报告保存的价格规则，显式提交合法新配置才换价（换价不改变范围与截止点）；v2 单会话报告的性能日分布时区随报告保存并在原范围重算时沿用，跨时区机器不再改写保存时区。JSON/CSV/Markdown 从同一结果投影费用与性能的精确值、依据与缺口，JSON 重载按文件内引用计量记录校验费用分区及记录、显式别名、命中规则的身份关系，拒绝同步篡改 token、金额与摘要或引用不属于该身份的规则；重算及更新结果的价格说明绑定本次提交快照，不受等待期间后选配置影响。JSON 可完整重载并离线复用，旧 v1/v2/v3 报告按保存能力展示，不补零、不自动升级原文件。
- **前端改版**：本地网页重组为「整体用量 / 会话分析 / 已保存报告」三标签；整体结果依次呈现实际范围带、总量/输入/输出/缓存命中率四张指标卡、可切换指标的按日纵柱趋势与模型/会话并排排行；证据区按块折叠，缺口与无法归桶量常显。费用与性能分析区位于 token 总览之后，网页价格加载、下钻沿用保存价格快照与明确换价经真实浏览器验收。
- 首屏紧凑化：范围带默认只显示摘要、完整元数据收进折叠，整体查询成功后查询区折叠为单行入口，失败时展开，原条件保留；1440×900 首屏可辨范围带、四张指标卡与日趋势日期、柱高，390px 无页面级横向溢出。
- 完整时间边界、候选浏览、下钻、定位、保存报告加载/重算/更新与导出等既有操作全部保留；日横条图由纵柱替代，过期提示与废弃样式已清理。
- 系统深浅配色（深色中性底+紫蓝强调）、窄屏卡片内滚动、键盘焦点与标签导航可用；计量、请求、报告版本与安装合同不变。
- 三期费用与性能的真实 Skill、网页、CLI 同值及原始记录独立复算、完整安装、三格式下载与离线复用已验收，最终复评闭合并按用户指令清理执行计划，三期及前端设计归并为现行实现合同，架构说明与可编辑架构图同步；前序独立未验事项仍按[实现文档第 10 节](./specs/2026-10-07-agent-token-audit-implementation.md#10-直接验收接受差异与当前状态)保留。

## V0.2

- **整体用量**：跨会话汇总、日趋势、模型与会话排行，支持列表筛选、分页、勾选及日期/会话下钻。
- **消耗解释**：展示记录来源、轮次时间线、耗时覆盖、内部调用与后代关系；图表联动定位明细，缺失与冲突如实标注。
- **本地网页**：按需浏览和统计，支持请求起点截止、保存报告重算与范围更新、JSON/CSV/Markdown 导出；服务仅监听本机并限制来源访问。
- **离线报告**：兼容 v1/v2/v3，支持图表、筛选和明细查看，精确保留大整数与时间边界；视图操作不改变统计结果，损坏报告明确拒绝。
- **来源与正确性**：完善 Codex 压缩调用、ZCode 后台任务与用量识别，修正去重、耗时、时间范围及记录引用校验。
- **保留限制**：ZCode 数据库与 rollout 分开计量，重试用量可能缺失；桌面入口不支持 `--current`，消耗解释的真实自然语言验收仍待补齐。其他限制与验收状态见 [README](./README.md#3-开发与验收)。

## V0.1

- 修复 ZCode 活跃轮次候选与请求截止点：合并 `model_usage`、`turn_usage` 和明确轮次事件的稳定 ID，同时保留生命周期未知；已确认的合成系统 message 不再作为用户请求候选或 `--request-id` 截止点，入队输入仅在 `promoted_message_id` 明确关联时与提升后 message 合并。
- 新增 Codex、ZCode 本地 token 统计 CLI 与自然语言 Skill，支持会话、显式连续/不连续轮次和带时区时间范围。
- 按来源身份去重，区分输入、输出、缓存及未知字段；关联后代和内部调用，工具累计报告单列，部分覆盖不冒充完整总数。
- 提供请求截止点、恢复/可验证分叉处理、Markdown/CSV/JSON 按需导出、旧报告展示及固定范围重算。
- 源记录只读，导出拒绝覆盖源文件及其别名，安装不自动覆盖已有不同内容。
- 当前限制：ZCode 数据库与 rollout 缺少统一调用身份，采用分开的来源入口；数据库可能缺少重试用量。Codex 种子轮次与一次 ZCode 桌面端正常授权报告已验证；ZCode 歧义选择、本轮修复后的桌面回归及真实用户分叉覆盖尚未闭合，暂不声明一期全部完成。
