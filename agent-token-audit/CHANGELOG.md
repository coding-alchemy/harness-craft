# 变更日志

## V0.3 — 2026-10-13

### 新增能力

- **费用估算与默认官网价**：按供应商、完整模型身份和明确计价条件计算费用，分币种展示精确小计、分项与未定价原因。新查询默认使用随包八款模型的官网价格快照，记录各来源读取时间；可改用自定义配置（`--pricing`）或仅统计 token（`--no-pricing`）。
- **官网价格更新**：通过 Skill 明确读取官网并更新实际加载的资源副本，保留每次读取时间和历史快照；完整校验后才切换默认价，部分成功或失败保留原默认。查询和安装不自动联网取价。
- **性能分析**：独立统计 TTFT、来源观测区间吞吐和工具耗时，分别展示样本覆盖、定义与缺口；工具原生执行耗时与调度至完成跨度分列，支持图表和证据定位，不改变 token 合计。
- **快捷时间范围**：整体查询支持今天、本周、本月、最近 1/3/7 天和最近 30 天，默认最近 7 天，保留全部时间与自定义。选择条件不自动统计；自然范围按所选时区解析，滚动范围按固定截止点计算，保存和重算沿用绝对边界。

### 体验与正确性改进

- **紧凑仪表盘**：网页按「整体用量 / 会话分析 / 已保存报告」组织，集中展示范围、四项指标、按日纵柱趋势与排行；查询成功后折叠配置、失败时展开并保留条件。支持系统深浅配色、键盘操作和 390px 窄屏卡片内滚动。
- **按需查看会话与证据**：会话排行、完整会话集合和长明细默认显示摘要，展开后生成并按 20 行分页。日期摘要就近展示，明确操作才进入会话；定位自动展开并选到目标页，分页不改变统计、覆盖或导出。
- **整体查询提速**：收敛浏览器重复校验和预绘，复用聚合索引及服务内有界解析缓存；来源变化或越界仍重新核验，服务退出即释放缓存。同冻结输入的 192 行端到端对照中，暖查询 8/8 单元中位数下降 32.8%～76.6%；冷查询中位数下降 1.1%～68.2%，其中 Codex 冷查询仅持平略降。
- **报告正确性**：修复可信原生工具耗时只有单侧时间端点时，合法报告被重载拒绝的问题；缺失端点保持未知，不反推时间。费用重载加强 token、金额、模型身份与规则引用一致性校验；确认零与未知分别展示，在途后选价格不串入已发查询，替换基准使旧响应失效。

### 兼容性与限制

- **保存规则不漂移**：原范围重算沿用保存的价格和显示时区，明确选择新规则才换价；无价父报告下钻保持无价。JSON/CSV/Markdown 从同一结果导出，合法旧 v1/v2/v3 报告仍可读，不自动补零或升级原文件；完整费用与性能重载由 JSON 承接。
- **费用是估算，不是账单**：默认快照按当前官网标准 API 价估算历史用量，不声称还原历史单价、套餐扣费或折扣；自定义 v1 配置仍按历史生效区间匹配。身份、档位或用量不足时不猜价。官方仅标注 OpenAI 的 272K 分界，当前规则在 `(272000, 278528]` 保留经用户接受的未计价空档。
- **性能依赖来源证据**：ZCode 数据库吞吐使用首 token 至来源完成时间的观测区间，包含完成事件处理开销；Codex 逐调用 TTFT/吞吐、ZCode JSONL 首 token 等证据不足项明确显示不可用原因。解析缓存仅用于服务内重复查询，CLI 单次进程不使用；实测提速伴随服务 RSS 和页面堆峰值增加。

费用与性能、默认价格及查询体验已完成真实两端 Skill、网页/CLI 同值、原始记录独立复算、完整安装、实际下载与离线复用验收。前序独立未验事项继续保留，详细合同、证据边界与已接受限制见[实现文档第 10 节](./specs/2026-10-07-agent-token-audit-implementation.md#10-直接验收接受差异与当前状态)；操作方法见[使用指南](./docs/usage.md)。

## V0.2

- **整体用量**：跨会话汇总、日趋势、模型与会话排行，支持列表筛选、分页、勾选及日期/会话下钻。
- **消耗解释**：展示记录来源、轮次时间线、耗时覆盖、内部调用与后代关系；图表联动定位明细，缺失与冲突如实标注。
- **本地网页**：按需浏览和统计，支持请求起点截止、保存报告重算与范围更新、JSON/CSV/Markdown 导出；服务仅监听本机并限制来源访问。
- **离线报告**：兼容 v1/v2/v3，支持图表、筛选和明细查看，精确保留大整数与时间边界；视图操作不改变统计结果，损坏报告明确拒绝。
- **来源与正确性**：完善 Codex 压缩调用、ZCode 后台任务与用量识别，修正去重、耗时、时间范围及记录引用校验。
- **保留限制**：ZCode 数据库与 rollout 分开计量，重试用量可能缺失；桌面入口不支持 `--current`，消耗解释的真实自然语言验收仍待补齐。其他限制与验收状态见 [README](./README.md#3-开发与验收)。

## V0.1

- 修复 ZCode 活跃轮次候选与请求截止点：合并 `model_usage`、`turn_usage` 和明确轮次事件的稳定 ID，同时保留生命周期未知；已确认的合成系统 message 不再作为用户请求候选或 `--request-id` 截止点，入队输入仅在 `promoted_message_id` 明确关联时与提升后 message 合并。
- 新增 Codex、ZCode 本地 token 统计 CLI 与自然语言 Skill，支持会话、显式连续/不连续轮次和带时区时间范围。
- 按来源身份去重，区分输入、输出、缓存及未知字段；关联后代和内部调用，工具累计报告单列，部分覆盖不冒充完整总数。
- 提供请求截止点、恢复/可验证分叉处理、Markdown/CSV/JSON 按需导出、旧报告展示及固定范围重算。
- 源记录只读，导出拒绝覆盖源文件及其别名，安装不自动覆盖已有不同内容。
- 当前限制：ZCode 数据库与 rollout 缺少统一调用身份，采用分开的来源入口；数据库可能缺少重试用量。Codex 种子轮次与一次 ZCode 桌面端正常授权报告已验证；ZCode 歧义选择、本轮修复后的桌面回归及真实用户分叉覆盖尚未闭合，暂不声明一期全部完成。
