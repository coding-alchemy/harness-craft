# Token 用量统计领域术语

本术语表约定 `agent-token-audit` 中已经讨论明确的业务概念。

## 领域语言

**会话**：用户在 Harness 中持续开展交互的一份逻辑对话，关闭后恢复仍属于同一会话；分叉产生独立会话。
_避免使用_：对话窗口、上下文窗口。

**任务**：围绕一个明确用户目标开展的工作，可包含不连续的多轮交互；一期一个任务限定在一个会话内。
_避免使用_：用“轮次”代指完整任务。

**轮次**：Harness 可识别的一次执行周期，可以接收执行中的追加消息，是任务内的交互单位。
_避免使用_：用“消息”或“模型调用”代指轮次。

**用户消息**：用户向 Harness 提交的一次输入；执行中的追加消息可能属于已有轮次。
_避免使用_：默认将每条用户消息称为一个新轮次。

**任务用量**：归属于任务的模型调用实际报告的用量，包含有明确归属的主代理、后代子代理及内部辅助调用；调用携带的历史上下文正常计入。
_避免使用_：用“主代理用量”代指任务总量。

**已记录小计**：当前可用记录中有依据的 token 数值之和；存在数据缺口时不代表完整总量。
_避免使用_：在有缺口时称“实际总用量”。

**统计截止点**：一份报告所纳入用量的时间上界；默认“截至现在”取本次统计请求开始时刻。
_避免使用_：把报告生成时刻当作默认截止点。

**任务范围**：一次统计明确选定的会话、轮次集合或时间范围，以及截止点；复用时保持原范围，明确要求更新后才扩展。
_避免使用_：仅凭任务名称代表确定范围。

**已保存报告**：某次统计结果及其范围的留存；重新展示它不等于读取当前记录重新统计。
_避免使用_：将“展示报告”和“重算用量”混称为刷新。
