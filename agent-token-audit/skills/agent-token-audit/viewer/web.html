Token 统计操作入口

本页由你显式启动的本地服务驱动，只在你点击对应按钮时读取来源；没有“当前会话”猜测，统计对象以你的明确选择为准。

Harness 与来源

整体用量

跨会话汇总：明确点击“查询整体用量”后才读取来源；默认纳入来源全部会话，实际范围、截止点与来源覆盖在结果中显示。点选日期下钻在后续版本提供。

时间范围（左闭右开；日趋势按显示时区归桶）
输入本地日期时间并配合时区；下界留空即不限；to 留空为“截至本次网页请求（服务入口固定）”。
显示时区（日界归属）
日趋势按该时区的本地日归桶；保存进整体报告范围。
代理范围

本次启动关联会话

该关联由启动链提供并经来源唯一匹配验证，不代表追踪 Harness 当前前台会话；转交请求只在你点击对应动作后执行。

会话候选

点击一行选择会话；派生关系与缺口如实显示，缺标题/时间/生命周期的候选保持未知。

稳定轮次

点击行切换选中，Shift+点击按列表显示顺序选择连续区段；显示序号不是身份，追加消息不产生新轮次。选择空缺即统计整个会话（turns=null）。

请求候选（截止点依据）

仅列出可作为用户请求截止点的候选；已确认非用户/合成的请求不出现在此。点击一行用该请求自身起点统计。

统计

时间范围（左闭右开，带时区）
输入本地日期时间并配合时区，完整秒与小数秒按原样提交；无时区文本不会被当作 UTC；from 与 to 都可留空。to 留空且未用请求起点时为“截至本次网页请求”。
代理范围

保存结果（基准）

展示旧报告不读取来源；重算按保存的会话、轮次/时间、代理策略与截止点读取当前来源并生成新 v2，不写回原文件。更新前先显示原范围与新范围差异，提交完整集合后才读取。

更新表单

保持同一 Harness/会话；轮次集合按完整集合提交（不自动追加），留空即整个会话；表单已预填保存的下界与轮次，留空时间下界即清除保存下界；截止点留空为更新到本次网页请求入口。
