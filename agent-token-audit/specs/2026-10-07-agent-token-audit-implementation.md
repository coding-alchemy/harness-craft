## 1. 定位、范围与阶段

工具回答“指定任务、会话或整体范围消耗多少，主要消耗在哪里”。Agent 用自然语言确定范围，Python 脚本确定性计量，浏览器展示同一份结构化结果。跨模型 token 相加只表示数量，不表示费用、同等工作量或质量排名。

| 阶段 | 范围 | 当前结论 |
| --- | --- | --- |
| 一期：初步构建基础能力 | 两端只读适配、会话/轮次/请求候选、任务范围、去重与后代归属、表格、按需导出、报告复用与安装 | 基础能力已形成；基础收尾与接受差异见第 10 节 |
| 二期：功能整体完善 | 可信定位与内部消耗、离线图表、本地网页操作、整体用量分析、记录解释与时间线联动 | 功能代码已形成；定位/网页按接受边界闭合，整体分析和解释仍有独立待补验项，不能称整期验收通过 |

当前只接入 Codex、ZCode。任务限同一用户会话及有明确关系的后代；跨会话整体分析不识别或拼接跨会话业务任务。普通查询不保存、不持续采集；只承诺可用记录的小计及缺口，不估算已删除或未报告用量。本文不定义未实现能力或后续路线图。

## 2. 系统结构与数据流

`audit.py → cli.main → operations.run(Query)` 与 `web.py → webapp.serve → Handler._run_action → operations.run(Query)` 共用操作层；自然语言 Skill 也是上述脚本的调用方。操作层负责来源选择、身份/截止点、保存范围复用和操作分派，不承担 argparse、HTTP 或终端渲染。

读取路径是 `codex.read` 或 `zcode.read/read_database → relations.bind → core.report/overview → formats`。适配器只读真实证据，归一化、去重后绑定继承/后代关系；内核对一份记录集合筛选、聚合并生成解释。浏览器 `shared.js` 校验和渲染保存值，`web.js` 管查询与交互状态，不另建统计内核。

运行需要 Python 3.9+，Python 产品代码仅用标准库；浏览器使用随包无损 JSON、原生 SVG 和控件，无构建步骤、CDN 或账号。报告、来源读取和输出三者分离；保存结果展示提前返回，来源路径只作证据，不能触发展示时扫描。

## 3. 来源、字段、去重与归属

### 3.1 Codex

默认读取 `CODEX_HOME/sessions`（缺省 `~/.codex/sessions`）或显式 JSONL。身份来自 payload，不从文件名、目录、模型角色或时间邻近猜会话。优先逐调用 `token_usage_record.payload.usage`，以会话及 `response_id` 去重；同源累计通知是校验视图，不再次加总。

旧记录仅在 assistant 回复唯一、核心字段有效且与累计差值相符时采用 `last_token_usage`。否则在完整源序列上先求累计差分，再筛选轮次集合。首个累计快照无零基线不当增量；重置/回退不截负为零。跨未选轮次或跨边界的区间不能按比例拆分，不能仅凭时间包络把整段计入。新旧覆盖重叠择一计量，字段冲突不吞掉其他可靠量。

`compacted.compaction_response_id` 明确对应调用时，将该调用移至内部辅助，不新增用量。无对应 usage 时说明可能已计或缺失。逐调用记录只有 usage 时刻而无开始时间，只画点，不补造调用跨度。

### 3.2 ZCode

默认优先现有 `~/.zcode/cli/db/db.sqlite` 的 `model_usage.raw_usage_json`；没有数据库时读 rollout/log。`--database` 和 `--source` 表示不同计量入口，不混合相加。DB logical_request_id 与 rollout requestId 无调用级桥接，不能凭 trace、相近时间或相同数值认定同调用。数据库入口核对同级 rollout，可读值以补充来源独立列示，明确跨源重叠未知、未并入小计、未按报告范围筛选。

rollout 以会话/request/attempt 识别调用，流式、非流式完成和失败的同 attempt 副本只计一次；独立 attempt 有 usage 分别计入。顶层与 response usage 冲突明确降级。DB 行是逻辑请求结果，不能冒充完整独立重试次数；`retry_count` 非零时说明调用总数与失败用量可能缺失。数值列默认零不能替代缺失 raw usage。计数日志与 rollout 只有在会话、调用、attempt 和类型可匹配时才形成可信缺口数；不能用日志总行数减 rollout 行数。

轮次候选合并 `turn_usage`、`model_usage.turn_id` 及明确事件的稳定 ID。只有 usage 也可选、可统计，但生命周期未知；后补事件只补同一候选。`session_input.kind=sendText` 是真实输入证据；只用 `promoted_message_id` 关联提升后 message，截止点取入队接收时间。合成 message、明确非用户输入及可靠别名拒绝作为用户请求；旧记录分类或关联字段缺失保持未知，不凭正文、时间或 ID 前缀合并。

字段核查覆盖 Codex 0.153–0.159、ZCode 0.16.3–0.16.9 的代表性记录，不承诺所有版本/操作系统/入口。已验证 BigModel Coding Plan/Start Plan 及 account 变体的同一写入器字段语义；其他供应商保留原值及未知，算术相等不证明包含关系。`cacheWriteTokens=0` 语义未确认，`reasoningTokens` 未报告；不能宣称确认零或外推全供应商。

### 3.3 去重与关系

同一真实调用合并全部来源定位；冲突只降级受影响字段，不平均、不多计。时间、粒度、状态、耗时的证据缺失可由可靠副本补齐，相反事实保留冲突；布尔值不当数字，等价时区字符串按同一时刻比较。来源文件有限快照只读完整行，损坏/未完成行标位置和影响，不复制原文到诊断。

明确父子/spawn/root turn 关系递归把后代归发起任务；后台跨下一轮仍归原任务。`workflow_child` 按 task_type 归后台后代，不能当分叉或额外一份内部量。关系缺失/冲突的已知量保留未归属，不按时间补链。压缩不新建任务，恢复沿同一会话累计；分叉只计新增调用，明确祖先关系和调用身份才剔除继承副本。重新发送继承上下文的新调用照常计入；缺祖先或累计基线保留不确定性。

逐端核查重试/失败、压缩/摘要、标题/会话辅助、子代理/后代、后台/其他五类来源。`internal_support` 的尚未核查、已核查可用、源未提供、存在缺口是能力状态，不是互斥用量组。可计量、仅计数、仅工具、关联不明分别说明；未读取不能写为源不存在。

## 4. 身份、范围与固定截止点

会话与请求分别确认。可信 Harness 上下文/环境身份须与源唯一匹配；无身份、多候选或冲突时显示稳定身份、已知时间、能力及原因并等待选择，不自动用最新会话。标题仅源有值时显示。范围明确直接统计；真实歧义导致不同结果才询问。已确定范围优先从当前对话或显式保存报告复用，不能仅凭任务名称恢复或扩展；重叠选集明确提示且不能直接相加。自然语言定位可按需读所选会话必要正文，数值事件和报告不保存正文，不建任务数据库或自动相似度分类器。

整个会话、单轮、连续/不连续轮次均支持；连续区段转为明确稳定 ID 集合，重复 ID 不增量。轮次是执行周期，消息不是轮次，追加输入未启动周期就不另造轮次。任务只排除未选轮次的调用，所选调用携带的历史上下文仍按实际 usage 计入，不扣提示词片段或反事实用量。轮次与时间约束可组合。

时间为带时区 `[from,to)`，要求 from < to。完整调用用结束/usage 时刻过滤；跨截止点不按比例切 token，累计区间跨下界或未选轮次不能拆，缺可信时间不静默计入。默认包含可靠后代及内部；`--main-only` 只主代理常规，另列内部辅助也排除（65 万任务样例中为 10 万）。

| 场景 | 截止点合同 |
| --- | --- |
| 自然语言本次/追加请求 | 使用本次请求自身可信创建/入队起点，不能用共享轮次或首请求起点；缺可信起点列可用边界待选择，不声称排除统计开销 |
| 独立 CLI | 参数解析/读源前的命令开始；显式历史上界覆盖默认，request-start 字符串本身不证明身份 |
| 网页截至现在 | HTTP 处理入口第一步固定 UTC `web_request_start`，不冒充浏览器点击瞬间或完成时间 |
| 保存范围重算 | 沿旧会话/集合、轮次、区间、代理策略、来源及 cutoff_source，不随当前环境或读取时间推进 |
| 明确更新 | 展示完整新范围、增删与边界差异后提交；截止点未指定才用新入口时间；切 Harness/单会话对象需新查询 |

范围固定不等于源快照冻结，后补记录可改变同范围重算。统计期间新消耗不能追入原固定报告；无法切分的调用列缺口。环境只给会话不证明请求；非用户/合成请求不因显式给 ID 而合法。

## 5. 指标、视图与完整性

指标保留 value、state、reason、源字段：源报告、推导、未知、冲突。完整输入包含源计量的缓存读/写；缓存读取不再加输入，缓存写入独立展示不默认再加，已包含于输出的推理量不再加。语义已验证且字段已知才得到非缓存读取输入=input-cache_read、total=input+output；源总量不符标冲突。

缓存率只取输入和缓存读取成对已知记录，计算两者总和之比，不平均逐调用比例；附 paired_records、输入及缓存覆盖。输入100/300、缓存90/0得到400/90/22.5%；缺一个字段不能宣称整体22.5%，零分母不适用，合法100%缓存率允许。调用覆盖率是另一指标，无可信分母不能报100%。

默认表列分组、输入、输出、缓存读取、命中率、总量。主代理常规、子代理常规、内部辅助、未分类互斥；内部性质优先，再按代理身份分组。模型/代理/轮次是同一记录集的独立视图，不相加；`--detail` 从保存视图投影。跨多轮累计区间单列无法拆分，不复制进每轮。缓存写入、推理、调用数、非缓存输入、耗时在详细信息提供。

直接 usage、可信调用计数、工具累计是独立通道；工具不拆输入输出、不加直接小计。会话辅助可进完整会话/整体，无法归任务的量不摊最近任务；继承副本、补充来源和排除诊断单列。未知模型不丢记录。

| 结果状态 | 含义 |
| --- | --- |
| partial | 有可靠已记录小计，仍未证明完整调用覆盖；字段缺失不补0 |
| count_only / tool_only | 分别保留计数或独立工具报告，不能因无usage吞掉结果 |
| unstatisticable | 无可用计量证据，未知不画零 |
| confirmed_zero | 范围内全部会话有完整零调用账本、截止前结束且无相反记录/缺口/工具；空列表不足以证明零 |

展示命中率四舍五入到两位小数，计算仍使用原始整数。表前给身份、范围、固定截止点，表后给 read_at、来源、缺口与覆盖。部分合计称已记录小计；视图隐藏行不改变合计、分母或范围。

## 6. 整体分析、日趋势、排行与下钻

`overview` 在单一 Harness 内默认纳入本次解析的全部会话，也可显式选稳定 ID 集合；保存实际集合，重算冻结，更新才改。父子闭包在一份已去重记录上选择一次，不能把逐会话报告相加；主代理策略只所选根的常规调用。新显式未知 ID 报错，保存集合缺失保留范围并说明缺口，不用旧值。

整体 v3 保存总览、`days`、模型/会话 `rankings`、`session_index`、独立通道及缺口。整体轮次视图不可用，不能跨会话把同名轮次混成一行。会话排行是该会话自身小计；进入单会话统计默认含可靠后代，两者口径不同需提示。

时区支持 IANA 名或 ±HH:MM，CLI 缺省系统本地偏移并声明，网页预填浏览器时区可改；无时区文本不当UTC。按可信usage/结束时刻归本地日；日范围保存为原范围与该日的交集，保留原边界精度/拼写，微秒和 DST 日界使用内核同一规则。已在整体范围的跨日累计区间不硬分日，存 `unbucketed` 独立对账；缺时间记录不进任何合计。

日桶缓存率仍成对加权，排行未知不归零，输入/输出/缓存/总量与覆盖对应。点日期只用保存的日模型/会话分布，不读源；点“进入该会话当日统计”明确发起独立v2，使用保存日交集和固定上界。整体→日期→会话逐级返回保留原查询及整体结果，不在v3嵌套或修改它。

候选列表文本筛选/列排序/固定页长分页只帮助下一次选择，结果行筛选只隐藏展示，重新计量必须明确点击。查询前编辑不改已有报告，图表与列表不生成筛选子集合计。

## 7. 记录解释、生命周期、耗时与联动

新v2/v3在同次统计结果上保存可选解释，不另计量。粒度分 `model_call`、`reply_usage`、`logical_request`、`cumulative_interval`、`unknown`；call_count=1或键前缀不能证明逐调用。计量行 `record_keys` 只引用本报告 records，独立通道只在自己通道定位，排除项不得加入计量行。

显式选中的轮次全部保留，含无 usage 或缺起止者；其他查询只纳入贡献记录涉及的轮次及有可信生命周期且与范围相交的轮次。无法证明落入范围、又未被显式选择或记录引用的候选只说明限制；生命周期跨出计量范围时保原始边界并标范围外上下文，不能截短后称完整轮次。

时间线按真实会话＋轮次身份组织，原始轮次与任务归属轮次分别保留；后代只按明确链归属。同名轮次在不同会话不串行，追加消息不新造轮次。可信时间稳定排序，缺时间放未知区；显示排序不改变累计差分。来源所读状态与截止前状态分别表达：结束事件在截止后就不能宣称当时已结束，只见起点称截至边界未确认结束，不能推断当前进程仍运行。

墙钟只取主会话所选轮次最早可信开始至最晚可信结束，不连续选集保留中间间隔；后代各列跨度，整体不造跨会话全局墙钟。缺端点、逆序、冲突、未在截止前结束或覆盖不全给未知原因。原生轮次duration是独立证据，不能填模型调用耗时。

条目耗时来自自身直接字段或可信起止，精度可比却矛盾列冲突，仅精度不同分别标注；拒负数、布尔、非有限数，明确0可显示。已有 activity.call_duration_ms 仅在所有纳入记录都有有效同粒度耗时才给完整和，否则为未知；已知子集、有效/缺失/冲突计数分别保存。逻辑请求耗时不混模型调用/累计区间；并行重叠不扣，墙钟≠耗时和，不因果分摊。串行两次10秒墙钟/和20秒；0–10与5–15并行墙钟15、和20秒。

图表行身份由维度类型及完整身份确定，轮次用结构化会话/轮次；截断标签、显示序号或拼接分隔符不能充当身份。图表、表格、键盘定位同一身份，一次选一个维度行/记录替换此前定位。指标切换保留、维度切换清除；“返回全部明细”与“清除行筛选”作用不同。定位只按保存键高亮/滚动/展开，空匹配给原因；行筛选不改定位集合、范围、合计、缓存子集或分母。每结果区闭包绑定自身报告，失效或坏文件清旧联动和导出绑定。

明细展开给完整身份、原始/归属轮次、粒度、时间语义、指标与耗时状态、分类/关系依据、文件完整路径及行号或DB表/行ID；不自动打开来源，不含正文/异常正文/headers/认证或模型生成的解释。内部分类只凭明确证据，五类来源的支持状态不能画成额外堆叠用量。

| v3 | overall会话集合、区间/tz、日桶/无法归桶量、排行/索引；轮次分布不可用 |

解释扩展只允许 v2/v3；v1 出现解释字段明确拒绝。三版均验证范围、非负精确整数/null、字段状态与覆盖、白名单隐私。解释扩展存在时验证枚举、时间、有限耗时、键唯一及行引用和分组/维度一致；坏引用/冲突结构/私密字段明确拒绝，不静默当无扩展。Python与浏览器分别校验不可信输入，只检查保存数据，不回源。JSON大整数全程用无损解析/序列化，不能普通浮点往返损坏。

选择在生成分组时保存行级引用，避免浏览器再维护累计跨轮、后代和日桶成员规则；v2/v3 可选扩展复用既有范围分支，代价是旧工具可能丢扩展。时间线复用 SVG/表格，不另引图表框架。

旧报告无解释合法，按已存字段有限定位，缺关系标旧报告未保存完整定位，不能猜补。当前show/JSON再次导出保原版本及扩展；旧工具可能忽略/丢解释，需支持解释的版本才保完整，旧工具不读v3明确报不支持，不降版本导出。重算才生成新的v2/v3，原文件不修改。

`show --saved` 只加载展示，零读源；`recompute --saved` 保旧范围/来源/截止，源缺仍可展示旧报告但新报告明确缺失，不能回填旧指标或解释。`--update` 唯一改范围，轮次/会话提交完整集合。HTTP缺字段保留、显式null转CLEAR清空、值替换；CLI不构造CLEAR。兼容差异保留：新 `report --from ""` 的 scope.from 为 `""`；保存更新空from与省略均沿旧下界。更新表单下界为完整带时区文本，不截秒/微秒，重开不改日期/时区组合。

默认表格/Markdown；`--format` 只改标准输出，显式 `--export --output` 才写。JSON、CSV、Markdown使用同一结果，CSV附范围、状态/原因、来源、解释粒度/单位/覆盖，不把独立通道再加合计；Markdown显示部分覆盖及来源。文件写入先拒来源/已加载报告及符号/硬链接别名，使用同目录临时文件＋原子替换，清临时文件。

## 9. 入口、安装、网页运行与安全

CLI操作为 `sessions/turns/requests/report/show/recompute/overview`。退出0=列举/展示成功或确认零，2=有效部分/计数/工具，3=不可统计，4=参数/读取错误；2仍须展示。请求起点、source/database和范围互斥按现有参数验证，失败不静默改参数。完整调用示例见[README](../README.md)。

本地服务由用户显式启动，只 `127.0.0.1`，系统空闲端口、每次随机凭据，fragment转页面专用请求头，不进报告/查询/日志。验证Host、Origin和凭据，无Origin也需Host＋凭据；静态资源白名单、无跨域/外部脚本连接。回环本身不足以阻止其他网页访问；不宣称防已控制账户的本地进程。服务启动/页面加载不读源，点击才每请求独立读取，无监听/缓存/后台队列，页面单飞，默认120秒超时。

启动限定来源真实根/文件及DB精确wal/shm、相邻关系log/rollout。发现和读文件前SourceGuard校验解析路径，拒越界符号链接；网页不能提交任意路径/命令/SQL/URL/服务器导出落点。保存input只是复算描述，明确重算也须属本次允许来源，不合则拒并提示按该源重启，不能偷偷换默认源。CLI原选择合同保留。

活跃WAL且有SHM时SQLite `mode=ro` 事务backup到工作区外快照；无SHM等情况复制稳定DB/WAL、核对前后stat，持续变化有限重试后失败。临时快照用后清，源不打开可写。诊断仅白名单元数据，错误给类型/位置而非原始正文，HTTP不记录请求日志。

启动关联会话只表示该次可信转交，不追踪实时前台；请求待用户点击才执行，之后另点截至现在是新网页请求。编辑Harness/会话清旧待提交选择，已显示结果按自身scope标识。seq负责响应配对，selectionVersion负责候选选择生命周期，baselineVersion负责文件/复算/导出；切走再切回旧候选仍丢弃，必须重新浏览。失效判定先于HTTP状态解释，已失效403也丢弃，后续明确有效请求按实况给fatal/连接失败。各结果区独立，坏文件/基准失效清旧操作；不重试、回填或自动补发。
